2. 实验为什么公平

同一原始 FITS
同一 float32 控制图→固定目标 ID、坐标、PSF
分别生成冻结注入图→A / B / C 读取
完全相同的图像→同一半径
一对一匹配
  • A：Gaussian 候选提案基线。
  • B：只把提案扩展为 Gaussian + DoG；候选阈值、FWHM、测量和背景规则不变。
  • C：不重跑检测，直接对同一 B 候选池应用现有 quality_passed 质量门；拒绝旗标保留。

无注入控制在目标位置的匹配半径内有 0 个已有候选。实际匹配半径是 3.0 px；规则为最近距离优先的一对一分配。

5. 这些结果能证明什么

模块实现固定输入、共享注入真值、候选到质量门的配对输出可运行并已落盘。
本轮实验结论只适用于所列强度、首帧真实背景、Gaussian 注入 PSF 和当前参数；观察到的增益或损失以表格为准。
未确认事项官方星表身份、真实目标总体完备率、整幅图误检率，以及真实场景中的运动目标回收率。

由于同一组坐标重复测试多个强度，样本之间有关联。本轮是可复核的算法工程对照，不作为广泛天文总体结论或物理解释。
