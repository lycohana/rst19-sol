# RST19 Rust 实现设计

原生桌面通过可取消的 Rust worker 执行研究工具；worker 与独立 CLI
共享 `rst19-core`，参数数组直接传递，不拼接 shell 命令。

FITS 原始整数位宽、首行辅助字段和曝光单位在读取边界保留。检测层依次
产生候选提案、原图测量、质量标志、模型比较和关联证据；星表身份与物理
来源需要单独的 WCS/目录证据。不同层的数量不互相替代。

序列链共享原始帧、有效参数和参考图，预测仅指导局部复核，不把缺失
观测补成检测。缓存绑定文件内容、输入顺序和科学上下文，损坏时重新计算。

实验比较使用冻结输入、哈希与目标/轨迹记录。已知注入真值、质量通过
候选和天空物理身份分别报告。新报告保留机器可读 CSV/JSON 和原图证据。

发布包由 Rust 构建程序生成，只包含原生程序和必要资产；通过包内实际
请求、文件哈希和原图不变检查验证。构建成功、数值回归、窗口视觉检查和
跨平台运行验收分别记录，不能相互代替。
