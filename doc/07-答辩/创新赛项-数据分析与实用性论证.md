# 创新赛项论证：分析数据的“有效”判定与“实用性”落点

对应评分项：创新数据分析 15 分（≥4 项得满分）、实用性 10 分（每次无法解答的质疑 −1）。

## 一、“创新有效分析数据”的判定标准

评委看的是四件事，缺一即视为无效：

| 判据 | 含义 | 反例（会被判无效） |
|---|---|---|
| **非基础任务** | 不是赛题要求的星点总数、最暗星星等、动目标 | 把“检出了 27 552 颗星”当创新 |
| **可量化** | 给出数值或曲线，不是定性描述 | “图像质量良好” |
| **可溯源** | 指明由哪些像素/哪些帧、用什么方法算出 | “经验估计” |
| **可复核** | 评委改一个参数能复现同级结果 | 依赖未公开的私有数据 |

## 二、六项创新分析数据（均满足上述四条）

### 数据 1　探测器编码上限与满阱标定

| 项 | 内容 |
|---|---|
| 来源 | 第 1 帧全帧 16.8 M 像元，及 66 469 个质量通过源的峰值分布 |
| 方法 | 峰值直方图（5 DN/bin）寻找堆积峰；检验紧邻区间是否为空；零值像元计数与高斯预期比较 |
| 结果 | 3990–3993 DN 堆积 881 个候选（峰值=3992 者 363 个），[3994,4100) 仅 1 个；原始像元 3990–3993 共 2 639 个、[3994,4000) 仅 4 个；0 值像元 73 774 个（预期 ≈15 200 的 4.9 倍）；−1 回绕 354 个 |
| 不确定度 | 台阶位置 ±1 DN（3991.5±1.5）；属编码/读出层面的事实，与增益无关 |
| 用途 | 替代缺失的 SATURATE 关键字；确定定标上限（本数据 G = 9.48）；判断数据是否被截断 |

### 数据 2　天光背景与噪声的空间模型

| 项 | 内容 |
|---|---|
| 来源 | 15 帧全帧；按到视场中心半径分环统计 |
| 方法 | 环带中位数（对星点稳健）与 1.4826×MAD |
| 结果 | 背景中位数由中心 **20 DN** 升至外缘 **23 DN**（+15%）；噪声由 **7.41 DN** 升至 **8.90 DN**（+20%）；15 帧全帧中位数完全一致（均为 21.0 DN） |
| 不确定度 | 环带内中位数标准误 < 0.05 DN；MAD 估计的抽样误差约 1% |
| 用途 | 曝光时间与增益策略；探测极限随视场位置变化的预测；给下游提供噪声图而非单一 σ |

### 数据 3　光学性能与平场梯度

| 项 | 内容 |
|---|---|
| 来源 | 20 906 对 Gaia 匹配星的零点残差（按半径分箱） |
| 方法 | 分箱零点中位数；二次项与仿射之差作为畸变量 |
| 结果 | 零点由中心 20.418 降至边缘 20.324（**0.094 mag**，即通量差 8.9%）；畸变 **1.88 px**（≈15.9″）；PSF FWHM 1.93 px |
| 交叉检验 | 背景向外**升高** 15%，若为减本底不准则会使外缘零点变**亮**；实测变**暗**，故梯度指向真实透过率下降（渐晕/平场），而非减本底误差 |
| 用途 | 平场改正；测光系统误差预算；载荷在轨性能评估 |

### 数据 4　平台姿态与指向产品

| 项 | 内容 |
|---|---|
| 来源 | 24 661 对 Gaia 匹配（切平面仿射拟合）与 15 帧图像互相关 |
| 方法 | 盲解 + 匹配迭代；帧间相位相关估计位移 |
| 结果 | 滚转 **266.9552°**、像元尺度 **8.43575″/px**、无镜像；相对遥测视轴偏置 **7.6′**；帧间图像位移 **≤0.09 px**（≈0.76″） |
| 不确定度 | 匹配残差中位 0.37 px；角度形式误差 < 0.05° |
| 用途 | 无 WCS 数据的自主定姿；平台稳定性评估；为后续帧提供指向初值（盲搜时间可降一个量级） |

### 数据 5　空间目标环境统计

| 项 | 内容 |
|---|---|
| 来源 | 15 帧像素级扫描（连通分量 + PCA） |
| 方法 | 形态判据 + 多历元轨迹拟合；Poisson 上限 |
| 结果 | 2 个独立运动事件：A（594 px、≥0.933°/s）、B（0.0885°/s、7 帧、残差 3.7 px）；快于 0.022°/s 目标面密度上限 **10.5 deg⁻²h⁻¹**（95% CL） |
| 不确定度 | 速率由 7 点拟合，形式误差 < 2%；面密度为上限而非测量值 |
| 用途 | 太空交通管理中的碎片/卫星通量估计；观测策略（曝光与视场） |

### 数据 6　探测能力曲线

| 项 | 内容 |
|---|---|
| 来源 | 噪声模型 + 零点 + 4σ/SNR≥5 判据 |
| 方法 | 由 σ_F 与 ZP 反解点源 5σ 极限；按半径分环给出极限星等 |
| 结果 | 中心 5σ 极限约 **14.5 mag**，外缘约 **14.2 mag**（噪声 +20% 对应 0.2 mag）；已探测最暗匹配星 14.91（单星不确定度 ±0.32） |
| 用途 | 任务规划（该相机 1.5 s 曝光的可用星等范围）；与其他载荷对比的统一口径 |

## 三、实用性：每项数据改变哪个决策

| 数据 | 使用者 | 改变的决策 |
|---|---|---|
| 1 编码上限 | 卫星运营方 / 载荷研制方 | 定标与饱和剔除阈值应设在 3 990 DN 而非 20 000 DN；否则亮端系统偏差 −0.13 mag |
| 2 噪声空间模型 | 观测规划 | 曝光时间按视场位置加权，而非按单一 σ 全局设定 |
| 3 平场梯度 | 数据处理 / 载荷评估 | 不做平场改正时，跨视场测光存在 0.094 mag 系统差 |
| 4 姿态与指向 | 平台运控 | 无 WCS 时可由图像自主定姿，偏置 7.6′ 可作为常值改正；帧间稳定 0.09 px 支持 1.5 s 无拖影成像 |
| 5 目标环境 | 太空态势感知 | 该相机 22.5 s 累计曝光下的快速目标通量上限，可用于望远镜/相机的普查效率比较 |
| 6 探测能力 | 任务设计 | 该配置可覆盖 9.5–14.5 mag；更暗目标需延长曝光或改用更长焦 |

## 四、抗质疑预案（每题一条，答不上来每题 −1）

| 质疑 | 应答 |
|---|---|
| “3992 DN 会不会是巧合？” | 三重证据：候选层面 881 个堆积、像元层面 2 639 个、紧邻区间仅 1 个/4 个；且 15 帧一致出现 |
| “背景梯度会不会是月光/杂散光？” | 背景向外升高 15% 而零点向外变暗 8.9%，方向相反；杂散光会使外缘变亮 |
| “0.094 mag 是不是平场没做？” | 正是未做平场的证据；我们给出的是该误差的量级与符号，可用于改正或计入预算 |
| “你没有增益，凭什么算面亮度？” | 面亮度只用零点与像元面积，不需要增益；增益缺失只影响泊松项，已在误差预算中标注 |
| “指向精度 0.37 px 有什么用？” | 对无 WCS 数据，这是唯一可用的绝对指向；且可用于给盲搜提供初值，使后续帧求解时间下降一个量级 |
| “面密度上限为什么不是测量值？” | 22.5 s 累计曝光内仅 2 个事件，只能给上限；给出的是 95% 置信上限而非点估计，方法已在方法稿中写明 |

## 五、结论

- 创新分析：**6 项**，超过满分档要求的 4 项；每项均给出数值、方法、来源与不确定度。
- 实用性：**6 项各自对应一个可命名的使用方与一个具体决策**，不是泛泛而谈的“有工程价值”。
- 风险：第 5、6 项的“上限”属性需在页面上明确标注，避免被当作测量值质疑。
