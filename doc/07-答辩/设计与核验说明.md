# RST19 答辩幻灯片：数值动画修订

日期：2026-10-20。20 页离线 HTML，以及同版 20 页静态 PDF。

## 本轮修正

上一版的扫光、呼吸光圈、曲线描边、条形展开和步骤淡入，没有表现算法的计算过程。本轮全部禁用。动态页只随数值状态变化：逐像素卷积、通量累加、核假设切换、阈值选择、共线去重。

## 五个计算演示

| 页码 | 输入与计算 | 可检查的输出 |
| --- | --- | --- |
| 4 | 原始 FITS 的 64×64 裁剪，调用当前 `statistics::local_background_rms`；16 px 分块 | 原始 DN、背景图 B、逐像素残差 I−B |
| 5 | 同一裁剪，调用当前 `masked_gaussian_response`、`standardize_response`、`response_proposals` | 逐像素加权和、Rust 参照值、标准化响应图、阈值变化后的真实候选 |
| 6 | 原图位置 (2929.855514, 3915.217082)，调用当前经验测光 `measure` 和面积覆盖函数 | 65 个正面积权重像素、逐项 a(I−b)、累积通量曲线、最终仪器星等 |
| 11 | 真实拖影裁剪：x=1486、y=276 起的 64×64 像素；点核与 8/16/32 px、24 方向线核 | 73 个实际白化核、对应响应图、固定位置 z、已检验最大值 Λ |
| 18 | 留存 PSF=1.93 原型的 9 条均匀长候选 | 每条候选的方向差、至代表脊线垂距、保留/抑制决策；最终 6 个代表 |

第 5 页可点击输入图定位像素，或拖动进度条；提案阈值可在 2–8 之间改变。在该固定裁剪中，阈值 2、4、8 对应 41、21、12 个候选。它们是局部算法候选数量，不是经过身份标注的真实天体数。

第 6 页最终背景 b=20、净通量 F=268.75、仪器星等 m_inst=−6.0733711823。中间累加值是教学用的未完成部分和，不作为完整源测量。

第 11 页的核来自当前 `glrt.rs` 频域参照实现中的 `kernel_from_samples`、`whiten_kernel` 与 `mf_z_freq`。核图保持像素等比例，显示正负权重；响应图使用固定色标。该实验使用裁剪独立估计的背景与白化模型、相位 0 核，不等同于全帧生产 Line 引擎的边缘归一化、不同锚点相位、精化或虚警标定。页面已注明这个区别。

第 18 页重放固定 PSF 原型的候选去重，9→6；产品目录 PSF=2.1513 的 3 条记录是另一配置，未与此处混合。

## 数据从何而来

`prepare_science.py` 只读原始 FITS 和当前源码，将 `glrt.rs` 与 `empirical_photometry.rs` 复制到项目 `output/playwright/rst19-deck/science-capture/`，追加导出中间数组的入口。原函数内容保持不变；`filtering.rs` 与 `statistics.rs` 直接从当前源文件编译。FITS 读取及未执行的依赖通过项目已构建的 rlib 链接，相关库另行绑定哈希。

导出的 `evidence/science-traces.json` 保存实际像素、核权重、响应数组、面积权重、逐像素通量贡献、各阈值候选、去重输入，以及输入 FITS、当前源码、链接库、采集器和编译产物的 SHA-256。

浏览器按计算顺序回放已导出的数组，同时直接计算当前像素卷积、当前核的内积、孔径部分和及去重决策。它不在浏览器中运行完整 Rust 管线，也不将可视化显示顺序冒称生产程序的并行调度顺序。

## 数值与交互核验

`evidence/页面核验.json` 是实际浏览器核验记录。以本地 `file:` URL 在 Chrome 中加载：

- 对 4096 个位置直接复算 Gaussian 卷积，最大绝对差 2.842170943040401e-14。
- 对全部 73 个核复算固定位置的内积，最大绝对差 5.684341886080801e-13。
- 另抽查 5 个核、4 个包含边界的位置，响应图最大绝对差 6.394884621840902e-14。
- 65 项孔径累加与 Rust 净通量差为 0。
- 实测阈值切换会改变候选数；播放推进计算索引；暂停保持索引不变；单步、拖动、核选择、来源抽屉及目录均检查通过。
- 20 页无 JavaScript 运行异常、缺失图片或检测到的正文越界。全部装饰性 CSS 动画的计算样式均为 `none`。
- 静态 PDF 在打印前将数值演示置于完成状态，按实际 PDF 渲染检查。PDF 没有交互。

数值一致性证明演示复现相应函数的计算，不证明模型物理正确、全帧误检率或天体身份。

## 其他科学口径

- 无色项零点 20.4231972、含色项零点 20.5008185 分开展示。
- 全部具备颜色信息的留出样本散度采用证据中的 0.3265388 / 0.3257701 mag，未继续引用旧口径 0.253。
- ±0.0005 是 M0 条件 WLS 参数形式误差，不是单源绝对精度。
- 3990 DN 上限是数据经验排除条件，不直接认证物理满阱。
- `along_profile` 按幅值筛样本，没有强制连续区间；scatter 使用超过半中位数的样本。
- 方向是像素索引坐标角；594 px 保留下界解释；目录记录和 moving 分类不直接等同物理目标。

## 操作与编辑

方向键/空格翻页；O 目录；N 来源；R 将当前计算复位并播放；F 全屏。计算页提供“播放计算 / 暂停计算 / 下一步 / 复位”和进度条；第 11 页可直接选择核。

编辑源为 `build_deck.py` 和 `science_slides.py`。完整项目内重新采集与构建：

```powershell
python doc/07-答辩/prepare_science.py
python doc/07-答辩/build_deck.py
```

重新采集需要 Rust、项目 release 依赖及原始 FITS。离线演示包中的 HTML 已内嵌数值数据，可直接打开，不要求这些运行环境。PDF 导出与核验脚本保留在项目 `output/playwright/rst19-deck/qa.cjs`。

本次新增的是局部实际计算与演示核验，没有重新执行完整星表匹配、全帧标定、全帧 GLRT 目录或完整序列分析。没有修改原有检测/测光/桌面程序逻辑，没有提交或推送。
