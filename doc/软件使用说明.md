# RST19 软件使用说明（Rust 版）

RST19 桌面前端和 71 项分析工具均由 Rust 实现。Windows、macOS、Linux 包中包含原生桌面程序、运算 worker、工具目录和字体。生产程序不要求安装 Python，也不需要修改系统或用户 PATH。

## 启动桌面程序

下载或构建对应平台的 ZIP，完整解压后启动包根目录中的 `rst19-desktop`（Windows 为 `rst19-desktop.exe`）。保留同目录 `runtime/` 与 `assets/`，只复制桌面 EXE 无法运行。

主界面左侧选择 FITS 数据目录和帧，中间查看预览与分析证据，右侧选择工具、填写参数并点击“运行分析”。首次可直接选择：

```text
doc/00-项目资料/原始数据/
```

界面默认把分析结果写入当前用户目录下的 `RST19-results`。原始 FITS 以只读方式参与分析；输出和缓存不会覆盖原始帧。完成后可在“检测源表”“结构化证据”“运行日志”和“产物浏览”页复核结果。

## 命令行使用

Windows PowerShell 示例（从完整解压的包目录运行）：

```powershell
runtime\rst19-native-worker.exe --catalog
runtime\rst19-native-worker.exe --tool rst19-sequence "C:\data\fits" --json-out "C:\results\sequence.json"
runtime\rst19-native-worker.exe --tool rst19-innovation "C:\results\sequence.json" --out-dir "C:\results\report"
runtime\rst19-native-worker.exe --tool rst19-injection --trials 1 --sources 2 --peak-levels 128 --out-dir "C:\results\injection"
```

每个工具支持自己的输入参数。使用独立 CLI 时，可在 `runtime/` 中运行相应的 `rst19-*.exe --help`；统一 worker 与桌面使用同一套 Rust 运算。

## 从源码构建

需要安装 Rust stable 和当前平台图形构建工具。仓库根目录运行：

```powershell
cargo run --locked --manifest-path backend/Cargo.toml --bin rst19-package -- build
```

构建会在 `dist/` 下生成平台 ZIP，并以包内 worker 执行单帧、序列、报告、注入和消融流程。Windows、macOS、Linux 的 CI 会分别构建和核验对应包；Linux 的系统图形库依赖见 [桌面构建说明](../desktop/README.md)。完整选项与回归证据见 [Rust 桌面说明](../desktop/README.md) 和 [验证记录](../backend/verification.md)。

## 结果边界

单帧星点、序列候选和运动轨迹是算法输出及其证据，不能单凭检测结果认定物理恒星身份。注入回收用于检查指定条件下的算法行为，不代表真实天空的总体精确率。相对测光也不会自动成为绝对星等。相关容差、冻结输入和已验证范围见 `backend/verification.md`。
