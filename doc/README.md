# rst19-sol 资料索引

本目录集中保存 rst19-sol 的赛题资料、数据解析说明、算法调研、创新分析候选和参考文献。根目录 [`README.md`](../README.md) 只承担项目入口和状态概览；新增研究结论、验证记录和外部资料应优先放在本目录，并在此索引中登记。

## 阅读顺序

如果刚开始接触项目，建议按以下顺序阅读：

1. [赛题与数据总览](./00-项目资料/赛题与数据总览.md)：确认比赛任务、评分项、数据边界和当前已知事实。
2. [本地数据核验](./00-项目资料/本地数据核验.md)：查看 15 个 FITS 文件的实测结果和未决问题。
3. [FITS 读取与校验](./01-数据解析/FITS读取与校验.md)：在编写算法前先统一数据读取、字节序和内存策略。
4. [星点识别方法](./02-星图识别/星点识别方法.md)、[星等估计与标定](./02-星图识别/星等估计与标定.md) 和 [星表路线深度研究](./02-星图识别/星表路线深度研究.md)：对应星图识别的两个方向及主办方提出的星表路线。
5. [运动目标识别方法](./03-星图分析/运动目标识别方法.md)：对应 15 帧序列中的多个运动目标检测。
6. [创新指标候选](./04-创新分析/创新指标候选.md)：在基础检测结果稳定后选择可解释、可复核的创新分析方向。
7. [参考资料](./90-参考资料.md)：集中维护外部标准、官方文档和论文链接。

## 文档状态约定

- **已核验**：来自当前工作区文件、可重复命令输出或原始比赛材料。
- **方法调研**：来自公开标准、官方文档或论文，尚未代表本数据集上的实验结果。
- **待实测**：需要在 15 张实际图像上运行、比较参数或人工抽检。
- **候选方案**：用于创新方向讨论，不能在比赛材料中直接写成已证实结论。

## 统一记录格式

每篇方法文档尽量包含以下四部分：

1. **目标与输入**：说明对应赛项、使用哪些图像/头字段、输出什么结果。
2. **建议流程**：列出可执行步骤、参数来源和备选路径。
3. **验证与风险**：明确如何判断结果可信，以及当前缺少什么证据。
4. **参考资料**：链接到原始标准、官方文档或论文，并说明引用用途。

这样可以把“资料中明确说明的事实”“可以采用的工程方法”和“尚未验证的假设”分开，后续实现、实验和比赛答辩都能追溯到同一份记录。
