# 第 1 帧恒星光度：可验证结果汇总（2026-10-17，Lead 复核版）

> 本文只收录**已由本仓库工具或独立脚本复算过**的数字。凡标"推断"的都需要实验裁决；
> 凡标"未知"的一律不填典型值。所有产物在 tmp/ 下（gitignored），文档与代码在版本控制中。

## 0. 一页结论

**已成立**
1. 指向解成立：roll = 266.9552°，scale = 8.43575″/px，无镜像；盲搜 peak/σ = 320.15，零假设上界 10.72；
   独立复算（另写实现，1024² 图）在同一 roll 得 187.5σ，相邻 1° 处仅 5.6σ。
2. 反推视轴 (129.6383°, −1.9161°) 与遥测 (129.5335°, −1.8454°) 相差 7.6′(54 px) —— 静态安装偏置，不是抖动。
3. 深目录（G<15.5，122,599 唯一源，逐像元覆盖率 100%）下：27,429 对位置匹配，残差中位 0.349 px；
   ZP(order0) = 20.4013 ± 0.0004，散度 0.1468 mag，n = 20,930；C = −0.0956 ± 0.0014；64 块偏移散布 0.0285 mag。
4. 对照（种子错 1°/40 px）：ZP 22.06、散度 0.2874 —— 逐轴比 配对 4.7×、残差 7.8×、散度 2.0×、块偏移 8.8×。
5. 检测/误差/编码三条独立结论：4 轮 3×MAD 裁剪在干净天空无偏（600 位置比值中位 1.0000）；
   DN=−1 = 65535 满量程；DN=0 低端削顶（观测 73,780 vs 高斯预期 15,200）；遥测区 y=0,x=0..103 永久掩膜。
6. 15 帧实际视轴稳定 ≤0.09 px（亚像素相位相关，峰/σ 437–484），而遥测 reports 最多 1.04 px —— 遥测不能当逐帧基准。

**还不能声称**
- 不能把 g_emp 写成 Gaia G 或 V；只能写 g_emp[450–750 nm nominal, response UNKNOWN]。
- 不能把 0.147 mag 当精度上限：它由系统项主导（见 §3）。
- 不能引用目标源的裸数字 14.34：它带 +0.11 mag 暗端系统项与未标定色项 ±0.14 mag。
- 不能给绝对星等、不能给 V/R、不能给极限星等（未做注入回收）。
- 不能声称 gain/读出噪声/平场已标定 —— 全部 UNKNOWN。

## 2. 测光链路（可复现命令）

```
# 1) 检测（生产配置）
rst19-sources <FITS> --psf-fwhm 3 --min-distance 3 --aperture-radius 4 \
  --threshold-sigma 4 --background-box-size 128 --min-flux-snr 5 --proposal-mode hybrid --out-dir <dir>
# 2) 指向盲搜（带自标定与对照）
rst19-astrometry-blind --sources <catalog.csv> --catalog <gaia.csv> --selfcal-mode matrix --control-trials 2 --out <dir>
# 3) 配对 + 零点 + CV
rst19-photometric-pairs --out <dir> --gaia <gaia.csv> --scale 8.43575 --rotation 266.9552 \
  --crpix-x 2080 --crpix-y 2092 --parity 1 --match-radius 4
```

```
g_emp = 14.340 ± 0.182 (stat)

波段：450–750 nm nominal, response UNKNOWN；ZP = 20.40 ± 0.0004；色项 C = −0.096 未应用（无 BP−RP）
可干净引用区间：G ∈ [10.0, 14.0]；覆盖区间 G ∈ [8.00, 15.50]
注意：该源 saturated 标志来自背景环内的 DN=0 削顶（孔径 r≤4 内 0 个 DN=0、0 个 DN<0，峰值 68 DN），不是峰值饱和
```

## 5. 必须向设备方/主办方索取（按优先级）

**阻断项**
1. gain（e−/ADU）与读出噪声 —— 决定亮端误差条与零点；
2. 满阱/饱和阈值/线性度曲线 —— 决定亮星能否用作定标星；
3. 16 bit 码值官方定义（是否无符号回绕、−1 含义、饱和码）—— 现有证据支持"回绕"，但需书面确认；
4. 是否已做 bias/dark/flat；若已做请给算法与参考帧；
5. 总响应曲线，或 滤光片透过率 × QE × 镀膜曲线 —— 决定能否把 g_emp 转成任何标准带；
6. **相机安装矩阵 / 视轴矢量 / 焦面朝向** —— 现有 7.6′ 偏置需要书面依据；
7. 时间系统（UTC/TAI/GPST）与 EXPOSURE 是否真为积分时间。

**可先做经验分析**
8. 光学设计（遮拦/渐晕/畸变规格）；9. 指向抖动与姿态稳定性；10. 杂散光与遮光罩；11. 逐帧坏像素/暗电流修正说明。

**提高精度**
12. 同设备标准星观测（同增益/温度档）；13. 平台轨道与视点（辅助数据自带 J2000 位置/速度，需确认定义）；14. 逐星真值表。

## 6. 工程缺陷清单（本轮实测发现）

| 缺陷 | 证据 | 建议 |
|---|---|---|
| rst19-plate-solver / wcs-validation 无对照基线，能输出自洽但虚假的解 | 7 匹配/0.66 px 的解在 ±400 px 偏移扫描下与噪声不可区分 | 验收改为"峰值 ≥ 3× 对照 99 分位"，否则 UNVALIDATED |
| rst19-gaia-merge 对马赛克永远 complete=false | catalog_merge.rs:481-490 要求 footprint 相同 | 加 mosaic 模式：完整性 = 覆盖审计 + 无触顶截断 |
| rst19-photometric-auto 栈溢出 | 默认 1 MB 栈耗尽；仅加 -C link-arg=/STACK:8388608 重链即跑完 | 在 profile.release 固定栈大小，或消除深递归 |
| 无 SIP/畸变模型（backend/src 里 SIP 出现 0 次） | 角落残差 1.88 px | match-radius ≤1 px 前必须补 |
| 默认 psf_fwhm=3 与实测 1.93 px 差 55% | Rust 经验 PSF（200 星） | 改默认或标 DEFAULT_NOT_MEASURED |
