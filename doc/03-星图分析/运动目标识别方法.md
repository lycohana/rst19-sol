# 运动目标识别方法

状态：**方法调研；待在 15 帧数据上验证**
对应赛项：星图分析 - 多个运动目标识别

## 1. 问题拆解

星表可以作为固定星场先验：先将目录源投影到每帧并建立静态星掩膜，再对未匹配且跨帧具有一致相对运动的候选做轨迹关联。星表路线的完整讨论见 [星表路线深度研究](../02-星图识别/星表路线深度研究.md)。

输入是 15 张同尺寸、同曝光时间、带 UTC 时间和姿态辅助数据的天基图像。目标不是简单寻找某一帧中的亮点，而是从连续图像中找到位置随时间变化、且能与固定星场和成像伪迹区分开的多个目标。

需要先解决两个坐标运动来源：

1. **成像系统运动**：卫星姿态、抖动、视场畸变或配准误差会让固定星点在像素坐标中移动。
2. **目标自身运动**：目标相对于星场的位移才是要识别的信号。

因此，先用固定星场估计帧间变换，再在统一坐标系中检测残差，是比直接对相邻帧做像素相减更稳妥的起点。

## 2. 推荐的分阶段方案

### 阶段 A：时间和数据质量

1. 读取每帧 `DATE-OBS`，按 UTC 时间排序；不要只使用文件名中的数字。
2. 校验尺寸、曝光时间、辅助数据和姿态四元数。
3. 计算每帧背景中位数、背景 RMS、饱和率和坏值比例。
4. 对所有帧使用一致的 mask 规则，特别标记首行前 104 个辅助数据位置。

### 阶段 B：星场配准

先在每帧提取足够多的高置信静态星点，用它们估计相对变换：

- 若主要是平移，先用相位相关或星点质心的稳健匹配估计 `(dx, dy)`。
- 若存在旋转、尺度变化或轻微畸变，升级到仿射模型；有足够匹配点时再评估更高阶模型。
- 用 RANSAC 或残差筛选排除运动目标、错误匹配和异常星点。
- 保存每帧的变换、内点数、残差 RMS 和置信指标。

`scikit-image` 的 `phase_cross_correlation` 提供基于互相关的亚像素平移配准；其文档也指出归一化选择对不同照明和噪声条件的表现不同。因此它适合作为平移基线，但不能替代对当前图像旋转/畸变的验证。

### 阶段 C：背景和差分图

把每帧变换到参考帧坐标后，构造静态背景：

```text
reference = robust_median(registered_frames)
residual_t = registered_frame_t - reference
```

实际使用时还需要：

- 对帧间背景偏置、增益和曝光差异做归一化；
- 对 PSF 变化做匹配或卷积，减少静态星残差；
- 用空间变化的背景 RMS 生成显著性图，而不是固定灰度阈值；
- 对差分正负残差都检查，因为配准误差可能产生成对亮暗结构；
- 把边缘、坏点、饱和拖尾、首行辅助区和大面积异常区域加入 mask。

基础版本可先使用中位数参考 + 局部 RMS 阈值。若静态星残差很多，再考虑更严格的 PSF matching 或 proper image subtraction。Zackay、Ofek 和 Gal-Yam 的 proper image subtraction 论文说明，经过准确配准和合理采样的差分可以提供用于瞬变检测的统计量；其假设和噪声模型需要在当前数据上重新核实，不能直接声称达到论文的最优条件。

### 阶段 D：残差候选点

对显著性图做局部峰值/连通域检测，并保存：

- 帧号和 UTC 时间；
- `x, y`、残差峰值、局部积分通量、SNR；
- 候选形状、面积、长宽比、正负残差结构；
- 是否接触边界、mask 或饱和区域；
- 与当前帧静态星目录的最近距离。

先保留较宽松候选，再在轨迹关联阶段使用时间一致性降低误检；过早使用严格单帧阈值可能丢掉低信噪比运动目标。

### 阶段 E：轨迹关联

对跨帧候选构建轨迹。15 帧时间跨度较短时，可以先用常速度模型：

```text
x(t) = x0 + vx × (t - t0)
y(t) = y0 + vy × (t - t0)
```

使用实际 `DATE-OBS` 的秒级时间差，而不是假设帧间隔相等。可选实现包括：

- 逐帧最近邻 + 速度门限；
- 匈牙利匹配或网络流关联；
- Hough/参数空间投票寻找共线运动轨迹；
- RANSAC 拟合常速度轨迹并剔除离群点。

一个合格运动目标轨迹应有多个时间点、合理的残差、连续或近连续的观测、稳定的方向/速度，并且不能被固定星场配准变换解释。单帧亮点或只由两个点支持的直线只能标记为低置信候选。

### 阶段 F：shift-and-stack 增强

当目标很暗、单帧 SNR 不足时，可以搜索 `(vx, vy)` 速度网格：把每帧按候选速度反向平移，再叠加。若速度假设接近真实值，目标信号会累加而固定星场和噪声不会以同样轨迹集中。

该方法计算量与速度搜索范围、步长、帧数和 cutout 数量有关，适合在差分基线之后作为增强方案。必须使用合成注入测量速度分辨率、边缘效应、误报率和不同亮度下的召回率，不能只因叠加后出现亮点就判定为真实目标。

## 3. 输出格式建议

建议每个目标输出一条轨迹记录和逐帧观测表：

```text
track_id
status: confirmed | candidate | rejected
vx_pixel_per_sec, vy_pixel_per_sec
speed_pixel_per_sec, direction_deg
track_length, inlier_count, fit_rms
per_frame: frame_id, utc, x, y, flux, snr, residual_score
quality_flags
evidence: cutout_paths, parameter_set, transform_ids
```

如果后续能建立像素尺度和 WCS，再转换为角速度；没有该标定前只能报告像素/秒或在材料中明确“不具备绝对角速度”。

## 4. 验证方案

### 4.1 合成运动目标注入

从真实 15 帧图像中选择空白区域或用真实背景，注入不同：

- 初始位置；
- 亮度/通量；
- 速度和方向；
- 目标 PSF、拖影长度和形状；
- 出现帧数和遮挡情况。

用已知真值评价检测率、误报率、位置误差、速度误差、轨迹长度和运行时间。

### 4.2 负样本与伪迹检查

专门记录以下伪迹是否被当成运动目标：

- 配准不足产生的静态星正负残差对；
- 饱和星拖尾；
- 首行辅助数据区域；
- 单帧宇宙线/热像素；
- 图像边缘和坏值；
- 由背景变化导致的扩散残差。

### 4.3 人工证据链

每个高置信目标应保存原始帧 cutout、配准后 cutout、差分 cutout、轨迹叠加图和拟合残差。答辩材料中展示完整证据链比只展示一张带框图片更容易解释科学性。

## 6. 当前不应声称的结论

- 还没有真实目标真值，不能报告“已找到多少个真实运动目标”。
- 还没有完整 WCS 和像元尺度，不能把像素速度直接写成角速度或轨道参数。
- 还没有在实际数据上比较平移、仿射和 PSF matching，不能预先指定唯一配准模型。
