# 实验记录模板（E0–E9）

> 每个实验一行一次运行。**不许事后修改已填写的行**；重跑另起一行。
> 冻结字段缺一项即视为该次运行无效。
> 模板与 `tools/xcheck/xcheck_config.json` 的段落一一对应。

## 公共冻结字段（每行必填）

| 字段 | 含义 |
|---|---|
| `run_id` | 运行标识（建议 UTC 时间戳 + 配置哈希前 8 位） |
| `utc_start / utc_end` | UTC 起止 |
| `input_fits_sha256` | 每帧输入哈希（逐帧列出） |
| `config_sha256` | 参数文件规范化 JSON 的 SHA-256 |
| `script_sha256` | 分析脚本自身哈希 |
| `tool_version / git_commit` | 工具版本与仓库提交 |
| `rng_seed` | 所有随机步骤的种子（注入、抽样、抖动） |
| `injection_table_sha256` | 注入表哈希（E7 必填） |
| `thresholds` | 该实验用到的全部阈值（逐项写出，不写“默认”） |
| `mask_policy` | y = 0, x = 0…103 遥测掩膜 + 其他掩膜的来源与哈希 |
| `operator / review_status` | 执行人 / 复核状态（未复核不得引用） |

## E0 像元编码与饱和裁决

- 输入：单帧原始 DN + 头部卡片；变量：编码假设 A/B/C；固定：无。
- 必填输出：负值分区（遥测区 / 亮核 / 天空区）、码值分布、`DN∈[32760,32767]` 计数、32767 平台段数、`-1` 平台段数、最负 20 个像元坐标与邻域均值、掩膜范围。
- 判据：非遥测负值落在亮核的比例；是否存在 32767 平台；码值是否为单峰。
- 失败判据：负值散布在平坦天空区 ⇒ 回绕假设否证。
- **本轮（20261017T100431650_2C449A5B）**：354 个非遥测负值中 98.31% 在亮核；6 个在天空区；246 个不同码；无 32767 平台；`-1` 6 段 ≥3 连续。

## E1 噪声结构与误差模型

- 变量：盒尺寸、环带几何、σ-clip 参数、孔径半径；固定：r_ap = 4（对比时）。
- 必填输出：盒噪声分位数、空间趋势、σ_ap(r)、估计量 RMS(r)、κ、背景平面斜率与二阶项。
- 判据：实测/模型比 ≤ 1.3；σ 空间动态范围决定能否用全局值。
- **本轮**：σ 中位 7.413、p99/p5 = 1.6；r = 4 估计量 RMS = 80.06 ADU，模型 67.65（比 1.18）；斜率 p95 0.0132 ADU/px；二阶项 p95 = 2.3e-4。

## E2 误差模型审计（只读）

- 输入：生产代码 + 单条保存记录；变量：gain、RN；固定：保存的通量。
- 必填输出：逐字代码摘录（含行号）、SNR/σ_mag 表、估计器辨识（N 个候选及其偏差）。
- 判据：生产 σ 能否由图像按文档估计器复现（偏差 < 5%）。
- **本轮**：通量复现 219.00；σ 不可复现（4.9062 vs 7.2698，−33%）。

## E6 假阳性基线（独立检测器，非生产）

- 输入：真实帧 / 反相帧（s → 2·median − s）/ 纯高斯噪声场；变量：阈值、FWHM 与椭率窗。
- 必填输出：三类计数、最大 SNR、纯噪声极值预期 z(N_indep)、伪影计数与成因分类。
- 判据：真实计数 ≫ 伪影计数 ≫ 噪声计数。
- **本轮**：65,948 / 434 / 2-0-7；噪声最大 SNR 5.46-5.61-5.68；EVT 4.925；伪影 13.4% 与负值像元重合。

## E7 注入回收（完备度）

- 输入：经验 PSF（分区）、冻结注入表；变量：星等 0.25 mag 步长、半径、拥挤度、背景水平。
- 冻结：注入表哈希、种子、注入位置与已知源的最小间距（≥ 3×FWHM）。
- 必填输出：回收率曲线、m_comp(50%)、m_comp(90%)、二项 CI、每分箱注入数。
- 判据：每 0.25 mag 分箱 ≥ 200 次注入、≥ 5 次实现；注入星互不污染。
- 声明：**注入回收测的是管线完备度，不是真实天体身份真值。**
