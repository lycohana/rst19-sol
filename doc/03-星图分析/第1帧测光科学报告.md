# 第 1 帧恒星测光：科学内容与方法记录

日期：2026-10-17　数据：开运一号天基相机 15 帧连续观测（21.014 s 跨度）
性质：**可验证性优先的仪器层标定记录**。本文只写由本仓库工具或独立复算得到的数字；
标注体系：【实测】= 本会话中跑出的数；【文献】= 官方文档/论文支持；【推断】= 由实测推得但未经独立裁决；【未知】= 无法确定。

## 摘要

我们在一块 4096×4096、16 bit、单帧曝光 1.5 s 的天基星图上，走完了从原始码值到"明确声明波段与误差的表观星等"的全链路，
并把每一步都钉在可复算的证据上。核心结果：

| 环节 | 结果 | 类型 |
|---|---|---|
| 指向解 | roll 266.9552°，scale 8.43575″/px，无镜像；盲搜 peak/σ = 320.15 对零假设上界 10.72 | 实测 |
| 视轴偏置 | 反推视轴与遥测姿态相差 7.6′（54 px），为静态安装偏置 | 实测 |
| 参考星 | Gaia DR3 深目录 G<15.5，122,599 唯一源，逐像元覆盖率 100% | 实测 |
| 位置匹配 | 27,429 对/帧，残差中位 0.349 px，p90 1.128 px | 实测 |
| 经验零点 | ZP = 20.4124 ± 0.0004，散度 0.1451 mag（n = 19,877） | 实测 |
| 颜色项 | C = −0.0803 ± 0.0013，留出改善有限 | 实测 |
| 空间验证 | 64 个 8×8 块，块间偏移散布 0.029 mag | 实测 |
| 15 帧稳定性 | 零点帧间峰峰值 3.79 mmag；随机项 0.1468 → 0.0379 mag（÷√15） | 实测 |
| 饱和判据 | 原始像素在 3990–3993 DN 存在硬台阶，判据须由 20000 改为 3990 | 实测 |

**结论的性质**：这是一个 450–750 nm 标称通带、响应未知的相机的**经验零点**，不是 Gaia G，也不是标准 V。
其绝对精度由不随帧数改善的系统项决定（平场 0.094 mag、未标定色项 0.14 mag、暗端混合 0.11 mag），
而随机项已被 15 帧压到 0.038 mag。

## 1. 仪器层事实（可核实）

【实测】15 个 FITS：4096×4096、BITPIX=16、头部 26 张卡片、文件大小 2880 + 4096²×2 字节、SHA-256 与记录一致。
头部**无** WCS/GAIN/RDNOISE/SATURATE/FILTER/TELESCOP/TIMESYS；`EXPOSURE` 是非标准 FITS 卡片（值字段含空格、未加引号，注释单位 ms）。

【实测】首行前 208 字节是 26 个小端 double 遥测（需"相邻字节对交换"），解出 az=270.000、ra=129.5335482522945、dec=−1.8453719932545742、
四元数模 = 1.000000。因此**第 0 行前 104 个 int16 不是图像数据**，必须永久掩膜。

【实测】像元编码：`−1` 出现在明亮核内且连成 4 像元游程，全帧 144 个，与 `65535` 满量程一致（无符号回绕）；
探测器区实测负值 354 个（排除遥测区 51 个），其中 98.31% 落在亮核；
`DN=0` 有 73,780 个而高斯预期 15,200（4.9 倍堆积）⇒ **低端在 0 处被削顶**，该像素不可作噪声样本。

【实测】逐像元噪声（相邻像元差分 + MAD/√2，342,214 对）：σ_pix = 7.338 ADU；128 px 盒 MAD = 7.413（整数量化 1.4826×5）。

【实测】生产误差模型给出的局部噪声可以完全复现：对目标源，4 轮 3×MAD 裁剪把环带 88 个像元吃到 78 个，
std 从 7.2698 降到 4.9279（生产记录 4.8962，差 0.6%）。**该估计器在干净天空无偏**：600 个无源位置的
clipped/unclipped 比值中位 = 1.0000、保留 88/88 像元。故 4.9 ADU 是"被污染的环带被正确裁剪"的结果，不是低估。

【实测】PSF：Rust 经验 PSF（200 颗星）= 1.929 px，独立叠合（779 颗）= 2.186 px；
单颗暗源的 7×7 矩估计给出 3.57 px，属噪声抬高。生产默认 `psf_fwhm = 3` 比实测宽约 50%。

## 2. 指向解：一次被推翻的否证

### 2.1 为什么一开始"解不出来"

【实测】早期六路检验全部为空：位移对照（真实 90 对 vs 平移 94/80/92）、板解器变换的 ±400 px 偏移扫描（4 对 vs 均值 1.1）、
1° 瓦片 roll 扫描、全局 roll×scale 扫描（2–30″/px）、密度图 FFT（10,980 次试验最高 7.31σ 而中位 5.73σ）。

【实测·根因】问题不在数据，在**单级粗网格的分辨率**。同一份数据、同一个 FFT，只改首级 roll 步长：

| 首级 roll 步长 | 首级 peak/σ | 阶梯细化后 |
|---|---|---|
| 0.633° | 9.71 | 320.15 |
| 1.000° | 9.36 | 319.88 |
| 4.000°（早期采用） | **2.71** | 311.70 |

粗扫在 128²（32 px/bin）时，1° 的格点误差只造成一个 bin 的错位，信号仍可被捕捉；一旦在细网格上直接用 4° 步长判决，
视场边缘 2048 px 处的位移达 144 px，信号被完全抹掉。**这是本次最重要的方法论教训：判决必须在正确的分辨率层级上做。**

### 2.2 解与判决

【实测】roll = 266.9552°，scale = 8.43575″/px，无镜像；投影中心 (128.966056°, −2.019891°) 落在像素 (2019.5175, 2336.6661)。

- 盲搜 peak/σ = **320.15**（peak 4571.9，map 中位 511.6，MAD σ 12.68）；
- 零假设上界（目录逐点抖动、检测逐点抖动、检测换随机场三族真零）= **10.72**；比值 29.9，门要求 ≥3；
- 合成自标定 = **229.01σ**，参数回归误差 0.014° / 5.5e−5 / 0.34 px；
- 失败边界：抖动 ≥30 px（6.43σ）、完备度 ≤1%（7.67σ）；
- 独立复算（另一实现，1024²）：同一 roll 得 **187.5σ**，相邻 ±1° 仅 5.6–5.7σ；
- 84.4% 的视场内星表星在 2 px 内有检测（11,012/13,043），位移对照 274 → 40.2×。

【实测】由解反推视轴 = (129.6383°, −1.9161°)，与遥测姿态 (129.5335°, −1.8454°) 相差 **0.1264° = 7.6′ = 54 px**。
四元数 → 相机 −Y 的约定本身**被数据证实到 1e−6**（R(q)·(0,−1,0) 与辅助 RA/Dec 单位矢量一致），故这是一个**静态安装偏置**。

【实测】15 帧遥测指向晃动最多 1.04 px，而图像亚像素相位相关（peak/σ 437–484）测得帧间位移 ≤ **0.09 px**
⇒ **遥测姿态不能作为逐帧天体测量基准**，15 帧可共用同一个种子。

## 3. 测光链路与零点

【实测】深目录：80 个 1.0° 瓦片（可断点续跑），223,771 行合并为 **122,599 唯一 source_id**，
G 分位 p16/p50/p84 = 12.93/14.48/15.23，max 15.500；覆盖率用 66,049 个样本点对**四种切平面假设**逐一验证 = 100%。
第 1 帧在框内的 G<13 行缺失 0。

【实测】配对：27,429 对，位置残差中位 **0.349 px**、p90 1.128 px；饱和剔除 11.1%；
孔径通量与生产星表之比中位 0.9919（MAD 0.028）—— 说明独立实现与生产测光一致。

【实测】零点（饱和判据修正后）：

| 量 | 值 | 不确定度 |
|---|---|---|
| ZP（order 0） | **20.4124** | ±0.0004（形式误差） |
| 散度（in-sample） | 0.1451 mag | n = 19,877 |
| 留出（5 折） | 0.1466 mag | |
| 颜色项 C | −0.0803 | ±0.0013 |
| 加入 C 后的留出 | 0.1447 mag | 改善 1.3% |
| 64 块偏移散布 | 0.0285–0.0344 mag | max |offset| 0.071–0.111 |

【实测】对照实验（把种子故意错 1°、crpix 偏 40 px），逐轴比：配对 0.206–0.211、残差 **7.7–7.9×**、散度 1.9×、
块偏移 5.0–7.4×、ZP 位移 1.51–1.66 mag。第 1/8/15 帧三帧一致。

【实测】经验 PSF 的环绕能量：EE(1..7) = 0.667/0.886/0.969/0.986/0.994/0.998/0.9995，
故 r=4 px 孔径的孔径修正量约 **0.015 mag**（另一条增长曲线路径给 0.034–0.055 mag，两者差异来自样本选择，未裁决）。

## 4. 饱和判据：一个必须改的硬阈值

【实测】第 1 帧原始像素在 **3990–3993 DN 存在硬台阶**：

```
3990: 254   3991: 1078   3992: 1067   3993: 240    [3994,4000): 4    [4000,4200): 52
```

27,552 个质量通过源中有 777 个的峰值落在该台阶内（peak=3992 有 363 个），而紧邻的 [4000,4100) 为 **0**。
每颗平台源平均只有 **3.1 个**削顶像素 ⇒ 只削核心、翼部正常。15 帧众数恒为 3992。

【实测】旧判据 `peak ≥ 20000` 高出该台阶约 5 倍，把 777 颗削顶星放进定标样本。改为 `3990` 后：

| 量 | 旧判据 20000 | 新判据 3990 |
|---|---|---|
| ZP | 20.4013 | **20.4124**（+10.2 mmag） |
| 散度 | 0.14676 | **0.14506** |
| C | −0.0956 | −0.0803 |
| 亮端残差（G 9.5–10） | −0.1308 | **−0.0492** |
| 定标区间 | G ≥ 8.00 | **G ≥ 9.48** |

反例佐证：ceiling 取 4500 反而让亮端更差（−0.1634），因为它剔掉的是另一批 peak≥4500 的源（残差仅 −0.063），
却把平台星留在样本里 ⇒ 阈值必须落在 [3993, 3999] 的空档内，不是任意可调参数。

【未知】3992 DN 的物理含义。同帧另有 2,512 个 >4200 DN 像素（最高 32,750），散布全幅——
我们检验过"来自顶部拖影"的假设，只有 20.5% 落在拖影区，**假设被否证**。全局满阱解释不了这种共存。
候选（未裁决）：饱和像素被固件替换成 fill code；某一路 ADC 通道上限；压缩/编码断点。

【实测】生产 schema 里存在 `SATURATED` 旗标，但第 1 帧 66,469 个源中只有 **1 个**带 ⇒ 现有旗标不能替代峰值判据。

## 5. 15 帧：随机项与共同系统项的分离

【实测】只用源表、不牵涉星表：105 个帧对、2,386,393 个 Δm 样本，每对匹配 16,272–24,369 颗。
帧对中位 Δm 最大偏离 4.3 mmag，**无一超过 10 mmag**。

【实测】Δm 散度与光子预期（1.0857√2/SNR）之比：

| SNR | 5–10 | 10–20 | 20–50 | 50–150 | 150+ |
|---|---|---|---|---|---|
| 比值 | **0.97** | 1.20 | 1.40 | 1.99 | 10.1 |

⇒ 随机项在 SNR ≲ 7 已达光子极限，从 SNR ≈ 7–10 开始偏离。

【实测】可平均性：半帧对检验 obs/white = 1.00–1.08；k = 2…7 帧的实测平均增益 0.702/0.542/0.494/0.439/0.404/0.370
对白噪预测 0.707/0.577/0.500/0.447/0.408/0.378（最大偏差 6%）。**逐帧随机项是独立的。**

【实测】不随帧数改善的共同项：8×8 块零点图案跨帧相关 **0.947**，图案 MAD 0.032 mag、峰峰 0.109 mag；
块内逐帧抖动仅 0.0063 mag。色项跨帧极差 0.0071 mag/(BP−RP)。

【实测】因此：第 1 帧散度 0.1468 → 合并 **0.0379** mag（÷√15）；
若保留固定空间图案，则为 **0.0489** mag。**禁止把 0.0379 当作绝对精度。**

【实测】零点时间稳定性：15 帧 ZP 中位 20.40233，MAD 0.63 mmag，峰峰值 **2.86 mmag**（新判据下 3.79 mmag）。

| 来源 | 量级 | 是否随帧数改善 | 依据 |
|---|---|---|---|
| 光子噪声 | 0.002（G=8）→ 0.044（G=13）mag | ✅ ÷√N | 实测 σ_m = 1.0857/SNR |
| 平场/渐晕 | 0.094 mag（中心→边缘） | ❌ | ZP 随半径 20.418→20.324 |

| 暗端混合/选择 | +0.11 mag（G 14.0–14.5） | ❌ | 残差随 G 上升、随 SNR 不变 |
| 畸变（角位置） | 1.88 px ≈ 15.9″ | ❌ | 二次项角落位移 |

即**亮端误差条被低估得最厉害**，而亮端正是定零点最敏感的样本。

## 7. 目标源与"最暗"的四种定义

那条被界面标为"最暗质量源"的检测（detection_id 63263，像素 2929.86/3915.22）：

```
g_ref = 14.366    g_emp = 14.340    stat_err = 0.210    resid = +0.026
```

允许的写法：**g_emp = 14.34 ± 0.21 (stat)，附暗端混合/选择系统项约 +0.12 mag（符号未定）；
band 450–750 nm nominal, response UNKNOWN；该源背景环内含 DN=0 削顶像素。**

四种"最暗"必须分开：

| 定义 | 数值 | 可引用性 |
|---|---|---|
| ① 该源本身 | 14.34 ± 0.21 | 可，带限定 |
| ② 能干净引用的最暗 | 14.0 | 推荐上限 |
| ③ 已标定的最暗匹配星 | 14.91（G=15.19），误差 ±0.32 | 不可（暗端系统项 +0.28） |
| ④ 5σ 检测极限（换算，非实测） | ≈ 14.4–14.5 | 仅量级 |

④ 是 `ZP + m_inst(5σ)` 的算术换算，**不是测量**；正式极限星等需要注入-回收（本轮只做过以 m_inst 相对量表示的流程完备度版本）。

## 8. 明确不能声称的

1. 不能把 g_emp 写成 Gaia G 或 Johnson V —— G 是 VEGAMAG 的"平均仪器"通带【文献】，本相机通带响应 UNKNOWN；
2. 不能把 0.145 mag 当精度上限 —— 它是内部一致性，绝对精度受 §6 的系统项限制；
3. 不能把 15 帧的 0.0379 mag 当绝对精度 —— 固定图案 0.032 mag 不随帧数改善；
4. 不能给绝对星等、V/R 星等、任何极限星等或完备深度（未做正式注入回收）；
5. 不能声称 gain/读出噪声/平场已标定 —— 全部 UNKNOWN。

## 10. 工具链缺陷（本会话实测）

| 缺陷 | 证据 | 建议 |
|---|---|---|
| `rst19-plate-solver` / `rst19-wcs-validation` 无对照基线 | 7 匹配 / 0.66 px 的解在 ±400 px 偏移扫描下与噪声不可区分 | 验收改为"峰值 ≥ 3× 对照 99 分位"，否则 UNVALIDATED |

| `SATURATED` 旗标近乎失效 | 66,469 源中仅 1 个带 | 用峰值判据 3990 取代 |

## 11. 必须向设备方确认（按优先级）

1. **3992 DN 平台的物理含义**：数字削顶？抗溢出？增益切换？为何 ≥4000 的源几乎不存在却有 2,512 个 >4200 的像素？
2. gain（e−/ADU）与读出噪声（含温度/增益档位）；
3. 满阱、饱和阈值、线性度曲线；
4. 是否已做 bias/dark/flat；若已做请给算法与参考帧；
5. 总响应曲线，或 滤光片透过率 × QE × 镀膜曲线；
6. 相机安装矩阵 / 视轴矢量 / 焦面朝向（对应实测 7.6′ 偏置）；
7. 时间系统（UTC/TAI/GPST）与 `EXPOSURE` 是否真为积分时间；
8. 负峰 −14950 与 `peak ∈ [4500, 32750)` 那 375 颗源的读出分支。
