## 1. 一页结论

**已经可以说的**
- 通量层面：在整数峰 (2930, 3915)、几何孔径 r = 4 px（49 像元）、环带 6–8 px（88 像元）下，
  独立复算得到 **flux = 219.00 ADU**，与保存记录一致 → **通量的算术是可复现的**。
- 误差层面：**不可复现**。该记录隐含的每像元噪声为 4.9062 ADU；同一个环带用文档给出的估计器
  `max(1.4826*MAD, std)` 得到 7.2698 ADU，IQR/1.349 得到 5.189 ADU，两者都更大。
  用 7.2698 代入同一公式得到 SNR = 3.449、σ_mag = 0.315（记录为 5.111 / 0.212）。
- 典型野值孔径误差：2000 个无源位置测得 r = 4 的孔径通量 RMS = **80.06 ADU**，
  是记录值 42.85 ADU 的 **1.87 倍**；对应 σ_mag 0.397。
- 检测层面：该源在 FWHM = 3 px 高斯匹配滤波下 SNR = **7.51**，FWHM = **3.40 px**，椭率 **0.035**，
  高于纯噪声场（3 次实现）的最大 SNR **5.46 / 5.61 / 5.68** → **它不是纯噪声极值**。
- 噪声结构：全域 128 px 盒噪声中位 **7.413 ADU**，p99/p5 = **1.6**（不满足“全局单一噪声可用”）；
  背景平面斜率 p95 = **0.0132 ADU/px**，二阶项对 r≈7 px 环带的偏差 p95 = **2.3e-4**（相对 r=4 噪声）→ 背景梯度可忽略。
- 像元编码：354 个非遥测负值像元中 **98.31%** 落在亮核内（邻域中位数 > 200 ADU），
  只有 6 个在天空区；负值有 **246 个不同码**、没有 32767 平台、但 `-1` 有 6 段 ≥3 连续（最长 4）。
  → 支持“无符号 16 bit 写入 int16 造成回绕”，`-1` 即 65535 满量程。

**现在不能声称的**
- 不能声称 0.212 mag 是这条源的误差；可复现的孔径统计值是 0.315–0.40，PSF 加权统计值是 0.145。
  **统计量不同，数值不同**，报误差必须先声明统计量。
- 不能声称 m_inst = −5.41 是星等或“最暗星”：它是 ADU 通量的对数编码，零点缺失，只能做同帧同配置差值。
- 不能声称“它是噪声峰”（否证，见上）也不能声称“它是可信恒星”（需要多帧静止性与星表确认，本轮未做）。
- 不能声称任何 Gaia G / V / R 星等，不能声称极限星等、完备深度、假阳性率指标（本轮的 434 / 3 只是工具内部的伪影与噪声基线）。
- 不能声称增益、读出噪声、饱和阈值、是否已做 bias/dark/flat —— 全部 **UNKNOWN**。

**最优先补的三件事**
1. 生产端对单个 source 输出逐项 debug（center / mask / N_ap / N_ann / background / noise 来源 / σ），
   把“4.9062 从哪来”定案。这是所有误差条的地基。
2. 取得可审计的 Gaia DR3 参考星表并做位移对照 + 分块留出（§5）。
3. 向设备方要 gain、RN、饱和/满阱/线性度、是否已做 bias/dark/flat、总响应曲线（§9）。

目标不是把精度除以 √15，而是：① 用多帧静止性把非恒星（拖影/碎片/宇宙线/回绕核）从参考样本中剔除；
② 实测帧间零点稳定性，得到**共同系统项上限**；③ 用帧间散布检验“SNR 是否可信”。
15 帧同源同探测器，系统项相关系数按 1 处理，写作 σ_tot² = σ_rand²/N_eff + σ_sys²。

真 gain/RN/饱和/线性度 → 误差条物理化；bias/dark/flat → 去掉平场残差项；
响应曲线 → 颜色项从经验拟合升级为可解释的合成测光比对；此时才谈转换到 V/R/G。

## 5. 参考星获取与逐星匹配方案（未执行，仅方案）

**接口**：TAP `https://gea.esac.esa.int/tap-server/tap`（同步 `/sync`，大结果走 `/async` + UWS，必须记录 job id）。
字段名以官方数据模型为准（DR3 `gaiadr3.gaia_source`）。

```sql
SELECT TOP 200000
  source_id, ra, dec, ref_epoch, parallax, pmra, pmdec,
  phot_g_mean_flux, phot_g_mean_flux_error, phot_g_mean_mag,
  phot_g_mean_flux_over_error,
  phot_bp_mean_mag, phot_rp_mean_mag, bp_rp,
  phot_bp_rp_excess_factor,
  ruwe, astrometric_excess_noise, astrometric_excess_noise_sig,
  visibility_periods_used, ipd_frac_multi_peak, ipd_gof_harmonic_amplitude,
  duplicated_source, non_single_star, phot_variable_flag
FROM gaiadr3.gaia_source
WHERE 1 = CONTAINS(POINT('ICRS', ra, dec), CIRCLE('ICRS', 129.533548, -1.845372, 7.5))
  AND phot_g_mean_mag BETWEEN 6 AND 17.5
  AND source_id > 0
ORDER BY source_id
```

- 锥半径 7.5°：视场半对角 6.92° + 尺度先验 1.87% + 指向余量。
- 键集分页（`source_id > 上一页末值`），另跑一次 `COUNT(*)` 做完整性审计；保存原始响应字节 + SHA-256 + UTC 提交时刻 + ADQL 原文 + job id + DR3 版本横幅。
- 亮/暗分两次查询：G ≤ 16 做标定样本，16 < G ≤ 19 只在小分区做暗端核验。
- 筛选分层：`ruwe < 1.4`、`astrometric_excess_noise_sig < 2`、`non_single_star = 0`、`duplicated_source = false`、
  `phot_bp_rp_excess_factor` 在官方经验关系 ±3σ 带内、`phot_g_mean_flux_over_error > 50`（并**分层报告**每条切掉多少）、
  避开已知变星（`gaiadr3.vari_summary` 左连，表中无记录 ≠ 非变星）。
- 图像侧：未饱和、非边缘、3×FWHM 内无邻星、多帧静止性通过。
- 匹配：1-1 互最近邻 + 几何 RANSAC + 通量一致性 + **位移星表对照**估误配率。
- 自行：`ref_epoch = J2016.0` → 2026.24，Δt ≈ 10.25 yr；pm = 1000 mas/yr ⇒ 10.25″ ≈ 1.2 px（按 8.438 ″/px 推算）。

## 6. 数学表达

**6.1 通量与仪器星等**

F = Σ_{i∈A} w_i (n_i − B̂_local)，当前 w_i ∈ {0,1}（几何判据 distance ≤ r），无分数像元权重。
m_inst ≡ −2.5 log10(F / t_exp)。t_exp 的误差是加性常数 +2.5 log10(t′/t)，**被零点完全吸收**，
只影响绝对流量类断言。

**6.2 生产误差模型（逐字见审计文档）**

σ_F² = source_variance + background_variance
= [F/g (若给 gain) + N_A·RN²] + [N_A σ² + N_A²/N_ann σ²]

已知缺陷：① σ 已含 RN ⇒ RN 项重复；② 缺 gain 时 Poisson 项为 0（UNKNOWN 而非 0）；
③ N_ann 用 clip 前像元数 ⇒ 背景估计项偏小；④ 无 κ（实测 κ ≈ 1.11–1.18）。

**6.3 本文推荐的分解式**

σ_F² = κ²[N_A σ_pix² + N_A²/N_eff,ann σ_pix²] + σ_AC² + σ_flat² + σ_blend²
其中 σ_pix 来自环带 max(1.4826·MAD, std)（**不再额外加 RN**，除非 RN 与 σ_pix 的构成分离）；
κ 由 E1 实测；σ_AC 由 E4 增长曲线；σ_blend 由邻星通量分数估计。

**6.4 标定（第三阶段）**

m_G,emp = m_inst + ZP + C·(BP−RP)，加权最小二乘（权重 1/(σ_inst² + σ_G²)），3σ 迭代剔除，
σ_ZP 用**分块 bootstrap**；颜色项可用性判据 `C/σ_C > 3` 且留出散度显著下降；参考与目标颜色区间必须重叠。
命名模板（强制）：`G_emp[450-750 nm nominal, ZP + linear (BP-RP), model_id=…, valid: G∈[…], BP-RP∈[…], σ_out=… mag]`。
**不得**写 `G`、`V`、`R`。

**阻止标准标定**
1. gain（e-/ADU）与读出噪声（含温度/增益档位）；2. 满阱、饱和阈值、线性度曲线；
3. **16 bit 码值的物理含义**：是否无符号回绕、`-1` 与极端负值的定义、饱和标记码（本轮数据显示很可能就是无符号回绕）；
4. 是否已做 bias/dark/flat；若已做请给算法与参考帧；5. 总响应曲线，或滤光片实测透过率 × QE × 镀膜曲线；
6. 时间系统（UTC/TAI/GPST）与曝光起止定义（`EXPOSURE` 是否真为积分时间）；
7. 首行 208 字节遥测是否**覆盖**第 0 行前 104 像元（本轮已确认覆盖，需确认是否可安全弃用整行）。

**可先做经验分析（不阻塞）**
8. 光学设计（遮拦、渐晕、畸变规格）；9. 指向抖动与姿态稳定性；10. 杂散光与遮光罩设计、地气光规避策略；
11. 逐帧是否做过坏像素/暗电流修正；12. **ADC 是否在 0 ADU 处截断**（本轮见 DN = 0 有 73,780 像元，
    而背景中位 21 ADU、σ ≈ 7.4，提示存在下限截断，会影响近地板测光）。

**进一步提高精度**
13. 同设备标准星观测（同增益/温度档）；14. 平台轨道与视点（辅助数据自带 J2000 位置/速度，但需确认定义与精度）；
15. 主办方逐星真值表；16. 同时段其他载荷观测（交叉守恒检查）。
