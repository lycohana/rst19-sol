# 饱和阈值修正与亮端偏差

日期：2026-10-17
状态：实验完成（T1/T2/T3 全部完成）；**3992 DN 的物理含义 UNKNOWN，未确认**

## 0. 结论摘要

1. 第 1 帧 quality_passed 源（27,552 颗）的 `peak` 分布存在**硬台阶**：3990–3993 DN 有一个尖峰（851 颗），紧接着 [4000,4100) 区间**完全为空**（0 颗），[4100,4500) 只有 5 颗。台阶存在于**原始 FITS 像素**中，不是检测流程产生的。
2. 旧判据 `--peak-ceiling 20000` 比该台阶高约 5 倍，把 758 对（854 颗）被削顶的源放进了定标样本；这些源的配对残差中位数为 **−0.1226 mag**（g_ref − g_emp，负 = 经验星等偏暗），正是亮端偏差的来源。
3. 把 `--peak-ceiling` 压到 **3990**：亮端残差（G 9.5–10 箱）从 **−0.1308 → −0.0492 mag**（第 1 帧，改善 0.082 mag）；15 帧合并后从 **−0.1203 → −0.0611 mag**；相对 12–14 等中带的相对偏差从 **−0.0997 → −0.0312 mag**。
4. 整体散度**变好**：第 1 帧 0.14676 → 0.14506（−0.0017 mag）；15 帧均值 0.14985 → 0.14845（−0.0014 mag）。
5. 代价：零点整体上移 **+10.1 mmag**（20.40219 → 20.41236），15 帧零点峰峰值从 **2.86 → 3.79 mmag**；且**定标样本中不再有 G < 9.48 的星**，G 8–9.5 变为外推区。
6. **不得表述为"3992 DN 已确认是饱和"**。可确认的是：存在硬台阶、与峰值削顶一致、与亮端通量低估一致。物理机制见 §6，标 UNKNOWN。

### 3.1 对 T1 提问的直接回答

**问：把 peak-ceiling 压到 3900 之后，G 8–10 箱的 −0.131 mag 偏差是否显著减小、缩小到多少？**

是。但要注意口径变化——压到 3990 及以下后，**全部 G < 9.48 的配对都消失**（它们的核心都在 3990–3993 被削顶），"G 8–10 箱"不再有定义。可比的量是两个：

- 同一 G 箱 **9.5–10**（新旧都还有样本）：−0.1308 → **−0.0492**，改善 **+0.0816 mag**，残差绝对值缩小到原来的 **38%**（n 从 367 掉到 19）。
- 相对 12–14 等中带的相对偏差（15 帧合并，样本更稳）：−0.0997 → **−0.0312 mag**，缩小到 31%。

**问：整体散度是变好还是变差？**

变好，但幅度很小：0.14676 → **0.14506**（−0.0017 mag，约 −1.2%）。因为平台星只占定标样本的约 4%（758 对 / 20,924 对），它们主要影响的是"零点/色项被拉偏"和低 G 端的局部残差，不是整体散度。

**一个非直观的对照**：ceiling 取 4500 会让亮端**更差**（9.5–10 箱 −0.1634，比 20000 的 −0.1308 还负）。原因：4500 剔掉的是 peak≥4500 的"另一批"高亮源（其自身残差中位仅 −0.063），却把全部 3991/3992 平台星留在样本里，于是样本被平台星污染得更纯。⇒ 阈值必须落在 **[3993, 3999]** 这个空档内才有意义，落在台阶之上和台阶之下都不行。

## 5. 推荐判据

**推荐 `--peak-ceiling 3990`**（等价区间 3900–3990：三者 ZP 相差 <0.00005 mag、散度相差 <0.0003 mag、n_zp 相差 ≤26）。

理由：
1. 3990–3993 是削顶平台，3993 以上到 ~4500 是空档；阈值必须落在空档内，取 3990 可确保平台星全部被排除，同时 3989 及以下源（每帧仅个位数）仍保留。
2. 3900/3950/3990 三者结果在统计上不可区分，说明结论对阈值具体取值不敏感（不是"调参调出来的"）。
3. 4500 与 20000 两个"台阶之上"的阈值都使亮端更差或持平，可作为反例写进方法学。

必须同时声明的限制：
- 修正后定标样本最亮为 **G ≈ 9.48**，G < 9.48 进入外推区，`applicable_range` 必须随之收窄，不能再声称 8–15.5 等全覆盖。
- 零点整体上移 +10.2 mmag，历史用 20000 得到的 20.4013 与新值 20.4124 **不可混用**。
- 该修正降低的是**亮端局部偏差**与整体散度（−1.4 mmag），对零点帧间稳定性是**略负作用**（2.86→3.79 mmag）。

## 6. 3992 DN 是什么：UNKNOWN（需向设备方确认）

**已确认的（可写入结论）**：
- 存在一个 3990–3993 DN 的硬台阶，它出现在原始 FITS 像素里，15 帧众数恒为 3992；
- 台阶紧邻上方（[3994,4500)）几乎无像素/无源；
- 平台源平均只有 3.1 个像素落在台阶值上，翼部正常；
- 这批源的配对残差系统性为负（−0.12 mag），与"核心被削平 → 通量低估 → 经验星等偏暗"一致；
- 把它们从定标样本剔除后，亮端偏差缩小约 70%。

**未确认的（不得写成结论）**：3992 DN 的物理含义。以下是候选假设，全部标为**推断**：

| # | 候选（推断） | 支持 | 反对 |
|---|---|---|---|
| H1 | 探测器某条链路满阱/FWC 折算的 DN 值 | 台阶锐利、跨 15 帧恒定、跨全画面 | **同帧存在 2,518 个 >4200 DN 的像素（最高 32750）**，若是全局满阱则不该出现 |
| H2 | 采集/固件把饱和像素替换为固定码值（fill code ≈3991/3992） | 台阶只跨 4 个整数值、逐帧恒定 | 若是纯填充码，不应该有 3990/3993 的"裙边"计数 |
| H3 | 某一路 ADC 上限（如 12 bit 与增益标度） | 3992 接近 4096 量级 | 削顶像素在空间上不局限在某一象限/通道（跨 1,940 列、2,143 行） |
| H4 | 压缩/编码方案在某一码值处的断点 | >4000 之上的取值在 4020–4180 呈 20 DN 等距（4020/4040/…/4180），有码表特征 | 该等距现象在 4200 以上消失（取值连续到 32750），只覆盖几十个像素，不足以解释 2,639 个平台像素 |

**给设备方的具体问题**（按优先级）：
1. 该相机/读出链路的满阱对应多少 DN？是 4096 量级还是 65535 量级？
2. 采集中是否对饱和像素做替换/填码？若有，码值是多少、是否与帧号/曝光相关？
3. 为什么同一帧里既有 ~3992 的平台像素，又有 >4200（直到 32750）的像素？二者是否来自不同读出通道或不同处理分支？
4. 是否存在按列/按通道的增益或饱和阈值表？（观察到平台值跨 3990–3993 共 4 个整数，可能是通道间差异）
