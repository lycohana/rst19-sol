# 星等估计与标定

状态：**已实现仪器星等与最暗可信源基线；绝对标定条件尚未确认**
对应赛项：星图识别 - 星等识别

## 1. 先明确“亮度最低”的含义

星表路线可以提供参考星身份和目录星等，但不能跳过图像检测、背景扣除和测光标定。完整的星表匹配、WCS 和“目录最暗星/图像最暗可信星”区分见 [星表路线深度研究](./星表路线深度研究.md)。

天文学中的星等是对数亮度标度，数值越大通常表示源越暗。因此“亮度最低的星”应解释为：在满足检测可信度和标定条件的候选星中，星等数值最大的那一颗，而不是像素值最小、峰值最低或背景最暗的像素。

单个像素最小值不能用于找最暗星，原因包括：

- 星光会分布在多个像素上，必须测量源的总通量或 PSF 参数。
- 背景、噪声、坏点和负值可能比星点峰值更低。
- 最暗候选通常最接近检测极限，误检和选择偏差更严重。
- 未经零点和响应曲线标定的原始计数只能支持同一图像内的相对排序，不能自动变成物理星等。

## 2. 可执行的两级结果

### 2.1 级别一：相对亮度/仪器星等

当没有标准星、滤光片响应、增益和零点资料时，先输出同一帧内可比较的仪器量：

1. 用 [星点识别方法](./星点识别方法.md) 得到候选源。
2. 对每个候选源在原始图像上用局部背景环做背景扣除后的孔径测光或 PSF 测光。
3. 同时传播局部背景 RMS、背景环有限像素数、孔径像素数和可选的 gain/read-noise，得到 `flux_error` 与 `flux_snr`。
4. 得到净通量 `F`，并按一致的曝光时间归一化。
4. 计算仪器星等：

```text
F_rate = F / t_exp
m_inst = -2.5 × log10(F_rate)
```

这里只能稳定地比较同一图像或同一成像系统下的相对亮暗。若使用不同曝光或不同帧，还要处理背景、增益、非线性和帧间响应变化。

### 2.2 级别二：绝对/标准系统星等

有可靠参考源和标定参数后，才能把仪器量转换为目标光度系统中的星等。一个常见的工程模型是：

```text
m_std = m_inst + ZP + C × color + extinction_term + residual
```

不同资料对零点、消光项和颜色项的符号约定可能不同，代码中必须通过标准星拟合验证，而不能只照抄公式。`ZP`、颜色系数、消光系数和残差应由参考星在同一设备、同一观测条件或已知转换模型下估计。

## 3. 推荐测光流程

### 步骤 A：测量源通量

当前代码以圆孔径和局部环实现轻量离线测光；Photutils 的 aperture photometry 同样以孔径求和为核心，并支持 circular/elliptical aperture 和 annulus。推荐每个候选源同时计算：

- 圆孔径净通量；
- 环形局部背景中位数或 sigma-clipped 统计；
- 孔径面积、有效像素数和背景噪声；
- 受 mask、边缘和邻近源污染的标志。

在未知相机增益时，至少使用背景项和背景均值估计项：

```text
σ_F² = N_ap × σ_b² + (N_ap² / N_bg) × σ_b²
flux_snr = F / σ_F
```

若提供 `gain_e_per_adu`，代码再加入 `max(F,0)/gain` 的源 Poisson 方差；若提供 `read_noise_adu`，加入孔径读出噪声方差。`snr`、`flux_snr` 和 `filter_snr` 是不同物理量，最暗源选择使用 `flux_snr`。

背景扣除可写为：

```text
F_net = sum(source_aperture) - bkg_per_pixel × effective_area
```

拥挤或拖影明显时，对比 PSF photometry。PSF 方法需要背景扣除和可解释的 PSF 模型，适合在亮度范围较宽、源互相影响的场景中提高通量估计一致性，但参数更敏感。

### 步骤 B：质量筛选

参与“最暗星”竞争的候选必须至少满足：

- 净通量为正，且达到预先定义的 SNR 阈值；
- 未饱和、未越界、没有严重坏点或辅助数据污染；
- 局部背景估计有足够有效像素；
- 形状接近点源模型，或异常形状有明确解释；
- 在孔径半径、背景环半径或 PSF 初值改变时，测光排序不过度跳变。

最暗星应取通过质量筛选后 `m_std` 或 `m_inst` 最大者，同时输出它的通量、`flux_error`、`flux_snr`、坐标、测光方法和筛选理由。当前 GUI 和 CLI 输出的 `faintest_detected` 已包含这些相对测光字段；无零点时不能把它叫作 Gaia G、Johnson V 或 `Mv`。

### 步骤 C：误差与检测极限

不能只给出一个小数点后很多位的星等。至少应报告：

```text
source_id
x, y
flux, flux_error
snr, flux_snr, filter_snr
magnitude, magnitude_error
calibration_mode
quality_flags
```

如果候选接近检测极限，应给出“最暗可信星”和“检测极限”两个概念：前者是当前图像中实际检测到的最暗合格源，后者是通过注入实验估计的可恢复阈值。二者不是同一个数。当前默认 `flux_snr≥5` 是质量筛选基线，不是由比赛示例数量倒推出来的真值。

## 4. 绝对标定的前置条件

当前材料已提供 `ra`、`dec` 和姿态辅助信息，但尚未确认完整 WCS、相机内参、像元尺度、滤光片/响应曲线、增益、零点、消光条件和参考星真值。因此，直接把本图像计数转换成标准星等会存在科学性风险。

如果使用 Gaia DR3 做参考，至少需要：

1. 建立可靠的像素到天空坐标映射，或先做 plate solving；
2. 按观测历元、视场和亮度范围检索候选星；
3. 处理 Gaia `G` 波段与本设备响应的差异，不能默认二者相等；
4. 排除变量星、拥挤源、饱和源和有质量标记问题的参考源；
5. 用多个参考星拟合零点/颜色项，并用留出参考星检查残差。

Gaia DR3 文档说明其数据包含 G、BP、RP 等宽带测光和天体测量信息，可以作为参考目录来源；这不等于 Gaia G 星等可以未经转换直接替代本设备的目标星等。

## 5. 推荐比赛输出

在标定资料不完整时，建议把输出分层写清：

| 输出 | 可交付条件 | 表述方式 |
| --- | --- | --- |
| 最暗可信候选 | 完成背景扣除、测光和质量筛选 | 报告相对排序/仪器星等，并给出误差 |
| 标准系统星等 | 有参考星、WCS 或可靠匹配、零点和响应转换 | 报告标定方法、参数和残差 |
| 检测极限 | 有合成注入和回收率曲线 | 报告指定召回率对应的极限，不冒充实际星等 |
