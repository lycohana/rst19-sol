# 星点识别方法

状态：**已实现可解释的 Gaussian/DoG/Starlet 多算法宽筛选→统一细筛选级联；Starlet 仅为实验模式；真实数据数量已测，但真值仍待星表/注入/人工验证**
对应赛项：星图识别 - 星点识别

## 1. 科学问题和计数边界

题目要求从指定图片找出星点并给出总数。图像算法首先观测到的是“源候选”，不是直接观测到恒星本体。因此本项目把结果拆成：

```text
原始像素 → 候选峰 → 局部测光与形状 → 可信点源 → 星表/注入/人工核验
```

代码对应字段如下：

- `candidate_count`：匹配滤波后经非极大值抑制的候选峰数；
- `returned_count`：实际计算并返回局部属性的全部候选数；默认不限制数量；
- `quality_count` / `star_count`：满足质量规则的点源数；
- `sources`：包含通过和拒绝候选，拒绝原因写在 `flags` 中；
- `quality_sources`：只包含 `quality_passed=True` 的源，供最暗源和星表匹配使用。

当前检测还会对显著正残差做连通域 PCA 审计。跨越多个 PSF 宽度、面积足够大且主/次轴方差比明显的结构会标记为 `LINE_ARTIFACT`；这类候选仍在 `sources` 中保留以便审计，但不进入 `quality_sources`，避免把亮线局部峰拆成大量星点。

`quality_count` 仍不是未经验证的恒星真值。它是“在明确的图像质量定义下的可信点源计数”，必须和匹配数、注入召回率以及人工抽检结果分开报告。

## 2. 数据准备和掩膜

当前 FITS 为单个 4096×4096、`BITPIX=16` 主图像。读取器保留原始存储值，另行生成以下掩膜：

1. 数据格式定义的首行前 104 个辅助字段位置；
2. NaN/Inf；
3. 整型图像中接近有符号 16 位上下限的值；
4. 当前数据背景约 21 ADU 且大量存在的精确 0 值（默认只对整数图像自动启用）。

自动饱和线设为 `dtype.max - 32` 只是数值边界保护，不是相机真实满阱/非线性阈值。拿到相机标定资料后应显式传入 `saturation_level`。精确 0 位于背景环时不直接否定源；只有孔径内被污染或背景环有效样本不足才拒绝源。

## 3. 背景和噪声模型

全图中位数与 MAD 经 sigma-clipping 后用于全局对照；检测阶段使用 128×128 网格统计局部背景和局部 RMS，再线性插值为 `B(x,y)` 和 `R(x,y)`。这样可以区分“整个图像的背景尺度”和“该星附近的测量噪声”。

背景图/RMS 图的必要性也被成熟源提取流程采用；[SExtractor 文档](https://sextractor.readthedocs.io/en/stable/Background.html)说明背景应随位置建模，并同时生成 RMS background map。当前实现没有声称替代完整 `Background2D` 或复杂散射光建模，网格大小需要通过空白区域和注入实验验证。

## 4. 候选检测：Gaussian PSF 匹配滤波

对局部背景扣除图像：

```text
D(x,y) = I(x,y) − B(x,y)
```

核心/CLI 历史基线使用圆对称 Gaussian 核进行匹配滤波，默认 `PSF FWHM=3 px`；GUI 当前默认已根据本地实测 PSF 切换为 `FWHM=2 px`：

```text
σ_psf = FWHM / 2.35482
R(x,y) = Gaussian(D) / Gaussian(valid_mask)
```

在 `R` 的局部峰上施加 `threshold_sigma` 和 `min_distance`。这里的匹配滤波是提高点源与随机像素噪声可分性的检测步骤，不等于已经完成 PSF 拟合；如果实测星像是椭圆、拖尾或空间变 PSF，应在下一轮实验替换模型。

默认 `threshold_sigma=4` 是候选保召回阈值，不是“4σ 就是真实星”的声明。4–8σ 应进行敏感性扫描，并把结果写入实验记录。

### 4.1 多算法宽筛选：Gaussian 不是唯一入口

为避免固定 FWHM 的单一 Gaussian 同时承担“尽量找全”和“排除伪影”，当前实现把 Gaussian 作为提案 A，并增加互补提案；每个提案只负责宽筛，不能绕过统一细筛：

| 提案 | 核心假设/作用 | 适合发现的候选 | 不能直接解决的问题 |
| --- | --- | --- | --- |
| Gaussian matched filter | 已知或近似已知点源 PSF | 接近当前 FWHM 的紧凑点源 | 固定圆 PSF 对椭圆、拖尾和空间变 PSF 失配 |
| LoG/DoG 多尺度 | 不同尺度上寻找局部圆形响应 | FWHM 偏离默认值的源、不同采样尺度的源 | 尖峰和宇宙线也可能有强响应；需多尺度去重 |
| Mexican-hat/wavelet | 以多尺度系数分离局部结构与背景 | 弱源、背景尺度变化和不同大小结构 | 系数相关、边缘响应和线状结构需要独立审计 |
| 局部阈值/连通域 | 正残差超过局部背景阈值 | 非圆结构、弱扩展结构和诊断样本 | 容易把噪声斑点、长线和一个星拆成多个候选 |

这些提案只负责形成 `N_wide` 候选并集，不直接进入 `quality_sources`。同一帧的候选按位置去重时保留 `method_hits`、检测尺度和各自响应；然后统一回到原始 FITS 做孔径测光、PSF 支持、形态、线状和掩膜审计。这样可以回答“哪个方法补回了候选”“并集增加了多少伪影”，而不会把多算法重复命中误当成多颗星。

宽筛选之后的细筛选至少比较 `H_noise`、`H_point`、`H_spike`、`H_line` 和 `H_blend` 五类解释。后续建立经验/分区 PSF 后，再加入最大似然 PSF 拟合、PSF 残差、模板相关性和去混叠；在没有实测 PSF、真值注入和阴性对照校准前，不把任何固定 `ΔBIC`、SNR 或算法命中数解释为恒星概率。两阶段“wavelet 候选 → 最大似然 PSF 验证”的公开天文流程见 [Puccetti et al. 2009](https://arxiv.org/abs/0910.2617)，多尺度 wavelet 候选生成见 [Freeman et al. 2002](https://arxiv.org/abs/astro-ph/0108429)。

本阶段的输出应分开保存：

```text
N_wide     = 多算法候选并集（高召回，不是星数）
N_fine     = 原始图像质量规则通过数（当前可信点源层）
N_temporal = 15 帧重复/轨迹规则通过数（稳定或运动候选）
N_catalog  = WCS/星表约束下的匹配数（身份核验层）
```

本项目已经按“先 LoG/DoG、再 wavelet/Starlet”的顺序完成第一轮本地对照；每种提案都使用同一批真实背景注入源、同一候选匹配半径和同一细筛规则，分别报告宽筛召回率、细筛精确率、伪影泄漏率、分裂/合并率、质心误差和耗时。当前结果没有证明 Starlet 相对 hybrid 有召回收益，因此它只保留为可审计实验模式。监督式 real-bogus 分类、实测空间变 PSF 和深度学习去混叠仍不作为当前依赖，因为还没有代表性人工标签与独立留出集；它们只能作为后续经过校准的可选后层。

## 5. 局部测光、误差和信噪比

候选坐标确定后，回到原始图像做半径 4 px 的圆孔径测光。背景用半径 `r+2` 到 `r+4` 的环估计：

```text
F = Σ_ap (I − B_local)
```

未知相机增益时，代码至少传播孔径内背景噪声和背景均值估计误差：

```text
σ_F² = N_ap σ_b² + (N_ap² / N_bg) σ_b²
```

如果给出 `gain_e_per_adu`，再加入 `max(F,0)/gain` 的源 Poisson 方差；给出 `read_noise_adu` 时加入读出噪声项。代码区分三个量：

- `snr = (peak − B_local) / σ_b`：峰值 SNR；
- `flux_snr = F / σ_F`：孔径通量 SNR；
- `filter_snr`：匹配滤波响应 SNR。

“最暗可信星”使用 `flux_snr`，不能用峰值 SNR 或单个最小像素代替。孔径测光误差的源项、背景项和背景估计项可参照 [Flux-Uncertainty from Aperture Photometry](https://web.ipac.caltech.edu/staff/fmasci/home/mystats/ApPhotUncert.pdf)。

## 6. 点源质量规则

默认质量边界已写进 `detect_sources()`，每次结果也写进 JSON 参数：

| 条件 | 默认值 | 目的 |
| --- | ---: | --- |
| `flux_snr` | ≥ 5 | 让通量测量明显高于局部背景误差 |
| FWHM | 0.8–12 px | 拒绝单像素尖峰和极宽结构 |
| 椭圆率 | ≤ 0.65 | 拒绝明显拉长的条纹/拖影候选 |
| sharpness | 0.005–0.85 | 拒绝过于弥散或尖锐的候选 |
| footprint | ≥ 2 px | 至少两个孔径像素超过局部 1 RMS |
| 3×3 PSF 支持 | ≥ 3/9 | 防止高单像素峰借随机正噪声通过旧 footprint 规则 |
| 边缘/掩膜/饱和 | 不允许 | 避免不完整或不可测量源 |

每个候选仍会保留 `fwhm_x`、`fwhm_y`、`ellipticity`、`sharpness`、`footprint_pixels`、`flux_error`、`flux_snr` 和拒绝标志。这样可以解释“为什么候选数大于可信数”，而不是静默删掉源。

这些边界是当前数据的第一轮工程基线，不应被误写成相机物理常数。真实星像的 FWHM 和形状应由高 SNR、孤立源统计或实测 PSF 给出；不同设备、焦距、姿态和运动状态需要重新验证。

### 6.1 定位质心与候选峰分离

弱源的“检测位置”和“测光质心”不是同一个误差问题。若直接把整个孔径内所有正残差作为质心权重，外圈随机正噪声会把标记位置拉离星像核心。当前实现保留原始 `positive` 残差用于通量、FWHM、椭圆率和 sharpness；定位时只在候选峰附近的 PSF 半径内使用：

```text
w(x,y) = max(D(x,y) − 0.5 R_local(x,y), 0)
         × exp(−r² / (2 σ_psf²))
```

并输出两套位置：`x/y` 是 PSF 加权亚像素质心，`peak_x/peak_y` 是匹配滤波产生候选时的整数峰坐标，`centroid_shift_px` 是两者的距离。GUI 的标记、悬停索引和小图默认锚定 `peak_x/peak_y`，CSV 仍保留两者，便于检查定位偏差；该修改不改变 ADU、孔径通量、SNR 或星等口径。

这条规则只解决定位被噪声拉偏，不能凭空提高暗星的可检测性。PSF 支持审计之前的定位对照曾记录候选数约 53,482、质量数约 25,943，定位修正后数量基本不变，而质量源的最大质心偏移由约 6 px 降到约 1.34 px；这组数字属于定位修正的历史基线。当前另增加 PSF 支持审计，首帧质量数为 23,627；它不是通过提高阈值或删除弱源制造“好看”的计数，而是把不具备小型核心证据的候选留在审计层并拒绝进入质量层。

### 6.1.1 单像素尖峰与 PSF 支持审计

上一轮小图抽检发现，旧的 `footprint_pixels` 只要求孔径内超过 `1σ_local` 的像素达到 2 个。对于“一个很高的单像素脉冲 + 一圈随机正噪声”，这个条件、孔径通量、FWHM 和 sharpness 可能同时被伪装通过。当前增加独立的 3×3 核心检查：

```text
peak_excess = max(I_peak − B_local, 0)
T_support  = max(2 × σ_local, 0.1 × peak_excess)
support_3x3 = count(D_core >= T_support)
```

默认要求 `support_3x3 ≥ 3`。它是“至少有一个小型 PSF 核心”的最低证据，不是完整 PSF 拟合，也不是把 3 个像素直接当成星点真值。边缘、掩膜、饱和或线状结构仍按原质量规则拒绝；支持不足的候选保留在候选层，并写入 `INSUFFICIENT_PSF_SUPPORT`，便于研究者检查阈值是否误伤暗星。该检查只影响 `quality_passed`，不改写原始像素、孔径通量、SNR 或仪器星等。

### 6.1.2 孔径内精确零值的局部容错

真实 FITS 中精确零值是稀疏、重复出现的异常像素候选，但格式说明没有给出明确的 `BLANK` 语义，不能把它们未经说明地解释成物理零亮度。因此当前只对“自动识别的精确零值”做局部容错：候选中心必须有效，圆孔径至少保留 `80%` 且不少于 `9` 个有效像素，被遮挡位置必须全部是有限精确 `0`。满足时保留源并写入非拒绝说明 `PARTIAL_MASKED`；任意非零外部掩膜、负值、NaN、饱和像素或中心被遮住，仍写入 `MASKED` 并退出质量层。对于有符号整型图像，测光孔径内低于负侧满量程 `90%` 的极端负码另写入 `NEGATIVE_OVERFLOW`；它只审计疑似溢出/饱和邻域，不把普通负噪声全部当坏点。

该边界对应代码参数 `allow_partial_zero_mask`，默认随精确零值自动掩膜开启，也可显式关闭。它只修改坏像素对质量层的影响，不对缺失像素插值、不修改原始图像，也不降低 SNR 或 PSF 支持阈值。首帧真实抽测中，`PARTIAL_MASKED=7,457`，但质量数只由 `24,641` 增至 `27,237`，说明许多候选还同时受低通量 SNR 或 PSF 支持不足约束。把所有负值外部掩膜后质量数反而为 `27,079`，所以负值全部等同坏点目前只作为研究对照，不是默认口径。

### 6.1.3 序列级固定 `-1` 异常码审计

对当前 15 帧原始 FITS 逐像素对齐后，发现每帧精确 `-1` 约 `130--156` 个，共 `2,185` 个；其中 `74` 个探测器坐标在 15 帧中始终为 `-1`。这支持“固定坏像素/无效码候选”的假设，但因头部没有 `BLANK`，比赛材料也没有定义 `-1`，当前不把它写入单帧默认掩膜，也不将所有负值视为坏点。

截图中的副响应 `(1274,3467)` 正好位于一个跨帧固定的 `7` 像素 `-1` 块附近，并同时含有正负极端码；这也是它虽然通过表面通量 SNR，却未能通过双 PSF 独立性检验的原因之一。当前单帧代码用 `NEGATIVE_OVERFLOW` 审计极端负码，序列研究则额外记录固定 `-1` 坐标。后续若取得主办方确认，应采用“固定异常像素进入掩膜、PSF/测光允许缺失像素”的方式，而不是直接删除所有与异常像素相邻的整颗源，以免误伤覆盖坏像素的真实亮星。

### 6.1.4 时序补提案的局部峰重定位

时间参考图只能给出“可能存在源”的坐标，不能保证它与每一帧的整数像素中心完全重合。注册重采样、四舍五入和亚像素质心抖动都会让一个真实点源的最大响应落在预测点的相邻像素；如果直接在预测整数点做强制响应，后面的 `support_3x3` 和 PSF 相关性会把定位误差误判成形状异常。

当前时序宽筛在每一帧预测坐标附近只搜索 `±1 px` 的 `3×3` 小窗口，选择最高的 Gaussian 匹配响应，再用这个局部峰计算核心支持和 PSF 相关性。搜索半径不是为了扩大候选邻域：它不改变参考图的候选坐标，也不允许跨到远处的随机亮点；它只修正注册/取整造成的一个像素级定位偏差。通量、星等和原始 FITS 像素仍由后续原图测量负责。

同一批 15 张 FITS、`4σ / min_distance=4 / FWHM=3 / flux_snr≥5 / support_3x3≥3`、Gaussian 单帧提案、参考 SNR `15σ`、时序 PSF 相关门槛 `0.80` 的前后对照为：

| 时序补提案定位 | 严格静态 | 持续候选 | 稳定/持续合计 | 候选共识通过 | PSF 相关拒绝 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 预测整数点（旧） | 5,276 | 14,919 | 20,195 | 14,790 | 1,336 |
| 局部 `±1 px` 峰（当前） | 5,276 | 15,524 | 20,800 | 15,395 | 669 |

新增坐标的抽样中位出现数为 `15/15` 帧；这说明原来的一部分漏检来自定位误差，但不能据此把全部新增坐标宣布为真星。仍需保留局部背景、PSF 形态、线状/坏点审计和星表/注入验证。序列缓存代际已随该行为变化升至 `29`，旧结果不会继续冒充当前口径。

### 6.2 单帧质量与多帧共识是两个输出

单帧 `quality_count` 是当前图像质量规则通过数，适合做候选审计和最暗源筛选；当同一数据目录存在 15 张连续曝光时，程序还把 `quality_sources` 在配准坐标中逐帧唯一关联：

```text
严格静态：presence ≥ ceil(0.8 N)，位移不显著，拟合 RMS ≤ 0.75 px
持续候选：presence ≥ ceil(0.5 N)，位移不显著，拟合 RMS ≤ 0.75 px
瞬态：未达到持续门槛，保留为待审计候选
```

这不是把 15 张图的候选数相加，而是使用“同一位置在多帧重复出现”作为额外证据。严格静态和持续候选必须分开报告：持续候选用于补回被偶发噪声、掩膜或饱和影响的源，但置信度低于严格静态。程序提供 `rst19-sequence --audit-out-dir`，从原始 FITS 生成按类别分层的时序小窗；颜色是算法类别，灰框是缺帧，不是人工真值标签。

### 6.2.1 注册稳健叠加只作弱星提案

时间中值对单帧异常很稳健，但对“每一帧都略低于候选门槛”的稳定弱星，统计效率可能不如均值。因此当前序列还提供注册后的 `coadd`：先按静态星场平移把 15 帧放入共同坐标，对每个像素围绕时间中位数做 `3×MAD` 裁剪，再对保留值求均值。它只负责提出坐标；坐标必须回到每一张原始 FITS，重新接受逐帧核心支持、孔径有效性、形状、线状掩膜、出现帧数和位置拟合审计。不能把叠加图上的一个亮点直接计作一颗星。

参数 `temporal_proposal_mode` 有三种口径：`median`（默认、较保守）、`coadd`（稳健叠加补漏）和 `both`（两类提案并集）。此外，`temporal_reference_min_snr` 只降低时间参考图的提案门槛，普通逐帧候选仍保持 `candidate_consensus_min_snr`；例如 `candidate_consensus_min_snr=15`、`temporal_reference_min_snr=12` 是召回抽测，而不是把所有单帧 12σ 候选当作质量源。

在本地 15 帧的真实抽测中，`both + 参考 SNR≥12` 相对 `both + 参考 SNR≥15` 新增了 `3,344` 个稳定/持续坐标，其中 `2,947` 个出现 `15/15` 帧；对这些新增坐标逐帧原图做的近似核心/形态抽样中，`2,919/3,344` 通过“多数帧核心支持 + 紧凑形态”代理检查，但这仍不是官方真值或完整孔径测光。相反，把普通候选门槛也降到 `10σ` 的对照进一步产生 `24,213` 条持续候选，`support=0` 淘汰增至 `3,972`，说明降门槛会同时放大固定纹理。因此产品默认仍保持 `15σ`，12σ 只作为界面和 CLI 的可审计召回抽测；详细数字见 [检测器实验记录](./检测器实验记录.md) 的注册稳健叠加与门槛敏感性章节。

局部峰重定位后又做了与 GUI 当前相同的 `median` 提案形式对照（本次实验的 PSF 仍为 `FWHM=3 px`）：普通候选门槛仍为 `15σ`、时序 PSF 相关仍为 `0.80`，只把参考图门槛从 `15σ` 降为 `12σ`，稳定/持续合计由 `20,800` 增至 `23,063`。相对 `15σ` 的新增注册坐标为 `2,448`，其中 `2,270` 条出现 `15/15` 帧，但新增轨迹的候选 SNR 中位数约 `15.86`，明显集中在弱边界。它们适合作为召回优先的待审计层，不足以支持把默认正式星表门槛直接改成 `12σ`。

上述 `temporal_reference_min_snr` 路径仍要求参考图种子达到较高的 `15σ/12σ`；它针对的是“单帧峰被坏像素/重叠污染”的漏检，不是“单帧 `flux_snr<5` 的稳定暗星”。后者由独立的**叠加暗星恢复层**（`stack_faint`）处理：直接在 15 帧注册中值/稳健均值参考图上用参考图自身的降噪噪声底重新检测（默认 `4σ`、`flux_snr≥5`），再回到每帧原始图做强制测光/支持/形状/持续性审计，单独计 `stack_faint_count`。真实 15 帧复测恢复 `9,857` 条低置信暗星，亮星 `ID 24651` 邻域（R=80）恢复 `17` 条；这是单帧噪声底压住的真暗星，不是噪点，但仍非官方逐星真值。详见 [检测器实验记录 8.42](./检测器实验记录.md)。

### 6.2.2 时序多尺度宽筛的单变量抽测

固定 `FWHM=3 px` 的 Gaussian 对大多数点源是一个合理的快速基线，但不能先验保证所有星像都具有完全相同的宽度。为检验“固定 PSF 是否造成漏检”，新增可选的时序多尺度宽筛：在时间中值参考图上并行使用约 `0.65× / 1.0× / 1.35×` 的 PSF 宽度，并取标准化响应的并集；回到逐帧原图后仍使用同一套局部背景、局部峰重定位、`support_3x3`、PSF 相关、出现帧数和位置拟合细筛。它只扩大候选提案，不改变单帧正式 SNR，也不把多尺度响应当作源级概率。

在同一批 15 帧、同一 `median` 时序提案、`15σ` 参考门槛、PSF 相关 `≥0.80` 下的单变量结果如下：

| 时序宽筛 | 严格静态 | 持续候选 | 稳定/持续合计 | 时序参考通过 | PSF 相关拒绝 | 支持不足拒绝 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 单一基准 PSF（FWHM=3 对照） | 5,276 | 15,524 | 20,800 | 7,127 | 669 | 3,468 |
| 窄/基准/宽三尺度 | 5,276 | 20,902 | 26,178 | 12,664 | 6,025 | 3,777 |

三尺度相对基线增加 `5,378` 条持续输出；按注册坐标 `3 px` 网格去重，新增约 `5,689` 条，其中 `5,597` 条达到至少 `12/15` 帧，新增候选 SNR 中位数约 `17.73`。这说明多尺度确实能找回一批固定 PSF 可能不匹配的时序提案，但同时带来更多 PSF 相关、形状和支持不足拒绝；严格静态数完全没有增加，且新增集合仍可能包含固定纹理或结构性伪影。抽样时序小窗也显示，弱持续候选中既有点状响应，也有接近噪声纹理的样本，不能只凭 `15/15` 出现或总数增长宣布为真星。

因此三尺度暂时保持为 CLI 的“漏检审计”开关（`--temporal-multiscale`）；GUI 默认仍使用单一基准 PSF，但当前基准宽度是 `FWHM=2 px`。本表的 `FWHM=3 px` 只用于多尺度机制对照。正式切换前必须补做分区实测 PSF、人工/合成注入回收、热像素和线状阴性样本，以及星表匹配；多尺度宽筛的正确结论是“扩大待验证候选池”，不是“新增了相同数量的恒星”。

### 6.2.3 当前 GUI 默认口径：hybrid 与 FWHM=2

截至 2026-09-02，GUI 的默认值已经从“Gaussian + `FWHM=3 px`”切换为偏召回的平衡组合：单帧和 15 帧都使用 `proposal_mode=hybrid`（Gaussian 与双尺度 DoG 候选并集），PSF `FWHM=2 px`，候选阈值 `4σ`，`min_distance=4 px`，通量 SNR `≥5`。hybrid 只负责扩大宽筛入口；候选仍必须回到原始 FITS，经过局部背景、孔径测光、三类 SNR、3×3 PSF 支持、形态、掩膜/饱和、重复码/异常负值数据有效性和线状审计。

选择 `FWHM=2 px` 的依据是首帧 PSF 抽测和候选/质量层对照，而不是单纯按“检测数量最多”选择。旧版经验模板的中位 FWHM `1.934 px` 属于筛选修复前的历史结果；修复后从完整候选表筛出的 20 个干净隔离质量源，中位测得 FWHM 约 `2.497 px`。加入极端负码审计前的相同 `FWHM=2` 真实抽测中，hybrid 的单帧质量层为 `29,295`，Gaussian 为 `28,993`；15 帧稳定/持续合计为 `30,297` 与 `30,135`。但 hybrid 的严格静态层为 `4,439`，低于 Gaussian 的 `4,998`，且支持不足拒绝更多。当前首帧 hybrid 复算为 `84,594` 个候选、`29,263` 个质量源；门控前的 `29,295`、只加入极端负码审计后的 `29,271` 和 `CODE_PATTERN` 初版口径 `29,153` 均为历史可比口径。因此它是“扩大召回并保留拒绝证据”的默认，不是每一个新增候选都更可信；需要严格静态星场时应切换 Gaussian 并单独报告。

15 帧默认时序提案为 `median`，参考图门槛 `15σ`，普通候选共识 `15σ`，逐帧补测门槛 `7.5σ`，PSF 相关 `≥0.80`，并在注册预测点 `±1 px` 的窄窗口中做局部峰重定位。时序多尺度、`both` 并集、局部去混叠和全量关联不作为默认，因为它们分别增加纹理候选、运行时间或内存压力；界面仍保留为显式审计选项。单图源上限默认留空，15 帧仍默认以每帧前 `6000` 个高滤波 SNR 源作为配准工作集，但完整 `candidate_count` 会保留并显示。

## 7. 当前实测证据

首帧 `20260330163205413_9901.fits` 的下表是加入线状审计前的历史对照，参数为 `FWHM=3 px`、`r=4 px`、128 px 局部背景网格和 `flux_snr≥5`：

| 候选阈值 | 候选峰 | 质量通过 | 被拒绝 |
| ---: | ---: | ---: | ---: |
| 4σ | 58,411 | 30,266 | 28,145 |
| 5σ | 50,893 | 30,162 | 20,731 |
| 6σ | 45,387 | 29,977 | 15,410 |
| 8σ | 37,656 | 29,205 | 8,451 |

相同响应图的负峰对照为 4σ/5σ/8σ/20σ 下约 515/93/58/57 个。它排除了“所有正峰都只是对称高斯随机噪声”的简单解释，但不能排除正向固定图样、热像素邻域或其他仪器结构。

加入 `LINE_ARTIFACT` 审计后，首帧在 `4σ / min_distance=3` 下仍有 58,411 个候选，但质量通过源变为 30,195 个；73 个候选带有线状标志，线状掩膜覆盖 10,683 个像素。这个变化不表示 30,195 就是真实恒星总数，而是说明长线伪迹已从星点下游层单独列出。

旧项目对同一首帧使用 DAOStarFinder、FWHM=3、shape 过滤和约 50×MAD 的高阈值，得到 8,511 个源；旧代码还使用峰值 SNR 代理星等。两套结果的检测对象、阈值尺度、掩膜和光度定义不同，不能用一个数字证明另一个正确。详细命令和误差解释见 [检测器实验记录](./检测器实验记录.md)。

上一版尚未启用 PSF 支持审计时，真实 15 帧全量复测曾得到严格静态 10,620、持续候选 6,805、合计 17,425；它只作为历史对照保留。当前加入该规则后的同一组复测得到严格静态 9,938、持续候选 6,249、合计 16,187；点源 `moving` 为 0，独立线状层单独报告。两个合计都不是比赛真值：它们依赖 `4σ / min_distance=4 / PSF FWHM=3 / flux_snr≥5`、12/15 与 8/15 持续性门槛、平移配准和质量规则，必须再用星表或有真值注入验证。单帧质量数约 2.3--2.4 万不能与稳定星场候选合计混写。

## 8. 合成注入和星表核验

当前没有官方逐星真值，下一轮验证必须包括：

### 8.1 合成/实测 PSF 注入

从真实空白区域估计背景和噪声，注入不同通量、FWHM、椭圆率、位置、重叠程度和运动速度的源，报告：

```text
completeness = recovered_injected / injected
false_positive_rate = false_candidates / candidate_count
centroid_error
flux_bias and flux_error calibration
```

注入位置需分别覆盖普通区域、边缘、零像素邻域、饱和源邻域和密集区域；否则得到的完备率只代表理想空白区。

### 8.2 星表交叉核验

有可靠 WCS 后，分别统计 `detected`、`matched`、`unmatched` 和目录预期源数。星表匹配用于身份确认和质量核验，不能把匹配成功数直接当作所有恒星数；星表不完整、波段不同、变星、运动目标和 WCS 残差都可能造成未匹配。
