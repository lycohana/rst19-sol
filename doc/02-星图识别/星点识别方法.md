# 星点识别方法

状态：**已实现可解释检测基线；真实数据数量已测，但真值仍待星表/注入/人工验证**
对应赛项：星图识别 - 星点识别

## 1. 科学问题和计数边界

题目要求从指定图片找出星点并给出总数。图像算法首先观测到的是“源候选”，不是直接观测到恒星本体。因此本项目把结果拆成：

```text
原始像素 → 候选峰 → 局部测光与形状 → 可信点源 → 星表/注入/人工核验
```

代码对应字段如下：

- `candidate_count`：匹配滤波后经非极大值抑制的候选峰数；
- `returned_count`：实际计算并返回局部属性的全部候选数；默认不限制数量；
- `quality_count` / `star_count`：满足质量规则的点源数；
- `sources`：包含通过和拒绝候选，拒绝原因写在 `flags` 中；
- `quality_sources`：只包含 `quality_passed=True` 的源，供最暗源和星表匹配使用。

`quality_count` 仍不是未经验证的恒星真值。它是“在明确的图像质量定义下的可信点源计数”，必须和匹配数、注入召回率以及人工抽检结果分开报告。

## 2. 数据准备和掩膜

当前 FITS 为单个 4096×4096、`BITPIX=16` 主图像。读取器保留原始存储值，另行生成以下掩膜：

1. 数据格式定义的首行前 104 个辅助字段位置；
2. NaN/Inf；
3. 整型图像中接近有符号 16 位上下限的值；
4. 当前数据背景约 21 ADU 且大量存在的精确 0 值（默认只对整数图像自动启用）。

自动饱和线设为 `dtype.max - 32` 只是数值边界保护，不是相机真实满阱/非线性阈值。拿到相机标定资料后应显式传入 `saturation_level`。精确 0 位于背景环时不直接否定源；只有孔径内被污染或背景环有效样本不足才拒绝源。

## 3. 背景和噪声模型

全图中位数与 MAD 经 sigma-clipping 后用于全局对照；检测阶段使用 128×128 网格统计局部背景和局部 RMS，再线性插值为 `B(x,y)` 和 `R(x,y)`。这样可以区分“整个图像的背景尺度”和“该星附近的测量噪声”。

背景图/RMS 图的必要性也被成熟源提取流程采用；[SExtractor 文档](https://sextractor.readthedocs.io/en/stable/Background.html)说明背景应随位置建模，并同时生成 RMS background map。当前实现没有声称替代完整 `Background2D` 或复杂散射光建模，网格大小需要通过空白区域和注入实验验证。

## 4. 候选检测：Gaussian PSF 匹配滤波

对局部背景扣除图像：

```text
D(x,y) = I(x,y) − B(x,y)
```

使用圆对称 Gaussian 核进行匹配滤波，默认 `PSF FWHM=3 px`：

```text
σ_psf = FWHM / 2.35482
R(x,y) = Gaussian(D) / Gaussian(valid_mask)
```

在 `R` 的局部峰上施加 `threshold_sigma` 和 `min_distance`。这里的匹配滤波是提高点源与随机像素噪声可分性的检测步骤，不等于已经完成 PSF 拟合；如果实测星像是椭圆、拖尾或空间变 PSF，应在下一轮实验替换模型。

默认 `threshold_sigma=4` 是候选保召回阈值，不是“4σ 就是真实星”的声明。4–8σ 应进行敏感性扫描，并把结果写入实验记录。

## 5. 局部测光、误差和信噪比

候选坐标确定后，回到原始图像做半径 4 px 的圆孔径测光。背景用半径 `r+2` 到 `r+4` 的环估计：

```text
F = Σ_ap (I − B_local)
```

未知相机增益时，代码至少传播孔径内背景噪声和背景均值估计误差：

```text
σ_F² = N_ap σ_b² + (N_ap² / N_bg) σ_b²
```

如果给出 `gain_e_per_adu`，再加入 `max(F,0)/gain` 的源 Poisson 方差；给出 `read_noise_adu` 时加入读出噪声项。代码区分三个量：

- `snr = (peak − B_local) / σ_b`：峰值 SNR；
- `flux_snr = F / σ_F`：孔径通量 SNR；
- `filter_snr`：匹配滤波响应 SNR。

“最暗可信星”使用 `flux_snr`，不能用峰值 SNR 或单个最小像素代替。孔径测光误差的源项、背景项和背景估计项可参照 [Flux-Uncertainty from Aperture Photometry](https://web.ipac.caltech.edu/staff/fmasci/home/mystats/ApPhotUncert.pdf)。

## 6. 点源质量规则

默认质量边界已写进 `detect_sources()`，每次结果也写进 JSON 参数：

| 条件 | 默认值 | 目的 |
| --- | ---: | --- |
| `flux_snr` | ≥ 5 | 让通量测量明显高于局部背景误差 |
| FWHM | 0.8–12 px | 拒绝单像素尖峰和极宽结构 |
| 椭圆率 | ≤ 0.65 | 拒绝明显拉长的条纹/拖影候选 |
| sharpness | 0.005–0.85 | 拒绝过于弥散或尖锐的候选 |
| footprint | ≥ 2 px | 至少两个孔径像素超过局部 1 RMS |
| 边缘/掩膜/饱和 | 不允许 | 避免不完整或不可测量源 |

每个候选仍会保留 `fwhm_x`、`fwhm_y`、`ellipticity`、`sharpness`、`footprint_pixels`、`flux_error`、`flux_snr` 和拒绝标志。这样可以解释“为什么候选数大于可信数”，而不是静默删掉源。

这些边界是当前数据的第一轮工程基线，不应被误写成相机物理常数。真实星像的 FWHM 和形状应由高 SNR、孤立源统计或实测 PSF 给出；不同设备、焦距、姿态和运动状态需要重新验证。

## 7. 当前实测证据

首帧 `20260330163205413_9901.fits` 在默认 `FWHM=3 px`、`r=4 px`、128 px 局部背景网格和 `flux_snr≥5` 下：

| 候选阈值 | 候选峰 | 质量通过 | 被拒绝 |
| ---: | ---: | ---: | ---: |
| 4σ | 58,411 | 30,266 | 28,145 |
| 5σ | 50,893 | 30,162 | 20,731 |
| 6σ | 45,387 | 29,977 | 15,410 |
| 8σ | 37,656 | 29,205 | 8,451 |

相同响应图的负峰对照为 4σ/5σ/8σ/20σ 下约 515/93/58/57 个。它排除了“所有正峰都只是对称高斯随机噪声”的简单解释，但不能排除正向固定图样、热像素邻域或其他仪器结构。

旧项目对同一首帧使用 DAOStarFinder、FWHM=3、shape 过滤和约 50×MAD 的高阈值，得到 8,511 个源；旧代码还使用峰值 SNR 代理星等。两套结果的检测对象、阈值尺度、掩膜和光度定义不同，不能用一个数字证明另一个正确。详细命令和误差解释见 [检测器实验记录](./检测器实验记录.md)。

## 8. 合成注入和星表核验

当前没有官方逐星真值，下一轮验证必须包括：

### 8.1 合成/实测 PSF 注入

从真实空白区域估计背景和噪声，注入不同通量、FWHM、椭圆率、位置、重叠程度和运动速度的源，报告：

```text
completeness = recovered_injected / injected
false_positive_rate = false_candidates / candidate_count
centroid_error
flux_bias and flux_error calibration
```

注入位置需分别覆盖普通区域、边缘、零像素邻域、饱和源邻域和密集区域；否则得到的完备率只代表理想空白区。

### 8.2 星表交叉核验

有可靠 WCS 后，分别统计 `detected`、`matched`、`unmatched` 和目录预期源数。星表匹配用于身份确认和质量核验，不能把匹配成功数直接当作所有恒星数；星表不完整、波段不同、变星、运动目标和 WCS 残差都可能造成未匹配。
