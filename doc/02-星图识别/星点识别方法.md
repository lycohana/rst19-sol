# 星点识别方法

状态：**方法调研；待在指定图片上建立计数基线**
对应赛项：星图识别 - 星点识别

## 1. 目标定义

从指定的一张天基图像中找出所有可被定义为星点的源，并给出星点总数。这里的“所有”需要在方案中转化成明确的检测边界：最低信噪比、允许的饱和程度、边缘截断处理、重叠星点处理、坏点/热像素/宇宙线伪迹排除规则。

不能把“阈值分割后得到的连通域数量”直接当作星点数。候选源中可能包括噪声峰、饱和拖尾、坏点、首行辅助数据污染、运动目标和重叠星点。

## 2. 推荐的可解释基线

### 步骤 A：数据准备

1. 按 [FITS 读取与校验](../01-数据解析/FITS读取与校验.md) 读取图像。
2. 对首行前 104 个辅助数据位置、非法值、边缘不完整区域和明显饱和区域建立 mask。
3. 记录原始数据类型、动态范围和背景分布；不在读取阶段随意拉伸或截断像素。

### 步骤 B：背景与噪声估计

先得到二维背景图 `B(x, y)` 和背景 RMS 图 `R(x, y)`，再在背景扣除后的图像上做检测。背景不应只用全图一个均值，因为大面积渐变、散射光或星点密集区域会改变局部基线。

Photutils 的 `Background2D` 使用网格化、sigma-clipped 统计估计二维背景及背景 RMS；实际项目中需要用空白区域和合成注入实验选择 `box_size`、滤波尺寸和 sigma clipping 参数。背景估计必须排除已知 mask 和极端亮源，否则亮星会抬高附近阈值。

### 步骤 C：候选点检测

建议先实现两个可比较的基线：

1. **局部峰值 + 连通域**：在 `D = I - B` 上使用空间变化阈值 `D > kR`，提取局部极大值和连通域。优点是简单、容易解释；缺点是相邻星点容易粘连，对 PSF 形状利用不足。
2. **PSF/高斯核检测**：用估计得到的 FWHM 构造二维 Gaussian kernel 做卷积，再找超过阈值的局部峰值。Photutils 的 `DAOStarFinder` 实现 DAOFIND 思路，并提供峰值阈值、FWHM、sharpness、roundness 等候选源属性；可以作为工程基线，但不能直接把默认参数当作本数据集的最优参数。

推荐的初始检测量为：

```text
threshold(x, y) = background(x, y) + k × background_rms(x, y)
```

`k`、FWHM、最小源间距和 sharpness/roundness 范围都应通过参数扫描和注入测试确定。方案中应展示“阈值变化 - 检测数量 - 误检数量”的关系，而不是只报告一个孤立数字。

### 步骤 D：源属性与重复合并

对每个候选源计算并保存：

- 峰值、背景扣除后的积分通量和峰值信噪比。
- 加权质心或 PSF 拟合位置。
- FWHM、sharpness、roundness、椭圆率和方向。
- 是否接触 mask、边界或饱和区域。
- 与其他候选源的距离，以及是否可能是同一个扩展/重叠源。

相邻候选点需要通过非极大值抑制、峰谷分析或多源 PSF 拟合处理。一个大连通域不一定只有一颗星，一个峰值也不一定对应一颗物理恒星。

### 步骤 E：计数与可信度

最终输出至少应包含：

```text
star_count
source_id, x, y
flux, flux_error, snr
fwhm, sharpness, roundness
mask_flags, detection_method, parameter_set
```

建议同时输出三种数值：

1. 原始候选数；
2. 通过形状、边界、饱和和 SNR 筛选后的可信星点数；
3. 在不同阈值/参数下的稳定计数区间。

比赛提交的最终数值必须明确采用哪一种定义，并给出筛选依据。

## 3. 参数确定和验证

当前没有官方星点真值标注，因此不能直接用“程序找到了多少个”证明正确。建议建立三层验证：

### 3.1 合成注入

从真实图像估计背景和噪声，注入不同亮度、FWHM、位置和重叠程度的模拟 PSF，检查召回率、误检率、质心误差和饱和处理。注入源的位置要避开首行辅助区域，或单独测试该区域是否误检。

### 3.2 参数稳定性

扫描 `k`、FWHM、最小距离和形状范围。若极小参数变化就导致计数大幅波动，说明阈值或背景模型还没有稳定，不能把该结果当作最终答案。

### 3.3 人工抽检

对检测结果绘制标注图，抽检亮星、暗星、边缘源、重叠源、异常像素和疑似运动目标。保存抽检样本和错误分类原因，后续写入答辩材料。

## 4. 方案中的科学性边界

- 星点识别是图像源检测问题，不等同于星表识别；没有 WCS 和星表交叉匹配时，不能声称已确定每颗星的天球身份。
- 原始图像灰度或积分通量不是星等；星等估计见 [星等估计与标定](./星等估计与标定.md)。
- `DAOStarFinder`、阈值分割和 PSF 拟合是候选方法，不代表它们已经适配当前开运一号天基图像。
- 若相机存在拖影、畸变或姿态变化，应调整点源模型；圆形 Gaussian 只是起点。
