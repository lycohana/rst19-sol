## 摘要

本文研究总光谱响应未知的 RST19 星图如何获得有明确证据边界的经验测光结果。流程包括原始码值审计、检测源表、参考星表、密度互相关几何种子、匹配细化、孔径测光及交叉验证。以 Gaia DR3 G 为参考拟合的 `g_emp` 是经验估计，不等同于已恢复仪器响应后的标准通带星等。

历史记录支持该视场存在强几何匹配、约 3990–3993 ADU 的异常码平台及跨帧重复的空间残差结构；但原稿将互相关图的稳健峰值对比度解释成高斯显著性、将总目录残差除以 √15 当作合并精度、将未知 gain 下的误差称为光子极限，均超出了证据。修订实现统一零起点像素坐标，计入背景估计误差，采用训练集内裁剪且全部留出星参与评分，并要求盲解的真实搜索、自校准与零对照使用相同搜索预算。当前工作能交付经验零点和条件误差，尚不能交付已验证的绝对精度或完整的随机/系统误差分解。

关键词：经验测光；Gaia DR3；盲解；交叉验证；相关误差；异常码审计

## 1 研究问题与数据边界

仪器标称通带为 450–750 nm，但滤光片、光学透过率和探测器量子效率的总响应未知。标称波长范围不能替代响应函数，不能将其默认成顶帽通带进行标准系统变换。

【历史记录】15 个 4096×4096 FITS，BITPIX=16，首末跨度 21.014 s。文件缺少 GAIN、RDNOISE、SATURATE 和完整 WCS；第 0 行前 104 个 int16 是遥测区。负码值集中于亮核，与异常编码或削顶相容，但仅凭 BITPIX=16 和亮核位置不能证明无符号回绕。新版屏蔽负码值，不擅自加 65536。零码值过多提示低端截断；它也可能受偏置、压缩或其他处理影响，需设备说明裁决。

【历史记录】深 Gaia 表有 122,599 个唯一 source_id。66,049 个采样位置落在查询瓦片覆盖范围内，只支持所检查投影假设下的采样覆盖，不是对全部 16,777,216 像素逐一核验，也不是星表完备度 100%。瓦片触顶、重复消歧、边界和 Gaia 本身的选择效应仍须另行审计。

## 2 方法与修正实现

### 2.1 像素坐标、孔径与背景

检测表的像素中心采用零起点 `(x,y)`。访问图像像素 `(ix,iy)` 时使用 `dx=ix-x, dy=iy-y`，不能再加 1。新版拒绝环带超出图像边界的源，屏蔽遥测及异常负码值；触及异常码的测光单独打标。

当前默认孔径半径 r=4 px，背景环带 6–10 px；原检测工具可能使用其他环带，其参数不能混写为同一个估计器。边缘像素以 4×4 子采样计算权重 wᵢ。净孔径通量为

`F = Σ wᵢ(Dᵢ − b)`，`m_inst = −2.5 log10(F)`。

这里 F 的单位是每次曝光的 ADU，没有除以曝光时间。零点因此依赖曝光与测量约定，不能跨曝光直接通用。背景 b 取裁剪后的环带中位数。

PSF 的历史估计（1.929、2.186 px）与生产默认 3 px 属于不同源群及估计方法；该默认应标为未实测配置，不能仅凭亮星叠合强制替换所有帧的 PSF。历史孔径修正 0.015 与 0.034–0.055 mag 尚未统一样本及背景定义，本轮不把其中任一数值作为已验证全局修正。

### 2.2 条件通量误差

令环带裁剪后样本数为 N_b，背景像素标准差为 s_b，gain g 的单位为 e⁻/ADU。新版使用

`Var(F) ≈ κ² s_b² Σwᵢ² + (π/2) s_b² (Σwᵢ)²/N_b + max[Σwᵢ²(Dᵢ−b),0]/g`。

最后一项仅在提供正且有限的 gain 时计入。π/2 是独立高斯样本中位数方差的渐近系数；裁剪、源污染、背景相关和像元删失使它只是近似。κ 在此只作用于孔径背景噪声项，不能未经检验同时当作背景估计及源泊松项的修正。

默认 κ=1 表示未实测膨胀修正，并不证明无相关噪声。历史空孔径比值 κ≈1.18 只对当时的孔径、环带、天空样本和估计器有效。若迁移到新版，需用冻结的空孔径样本重新估计。

`σ_m ≈ (2.5/ln10) σ_F/F` 是高信噪比线性传播近似；低 SNR、截断及混合源可能产生非高斯分布和选择偏差。没有 gain 及独立误差验证，不能称其为“光子极限”。若比较源泊松与背景项，条件是 `F > g N_ap s_b²`（整像素近似），不能在未知 g 时给出唯一 ADU 临界值。

### 2.3 几何种子与盲解检查

密度图在 parity、roll、scale 上搜索，FFT 搜索平移。峰值指标

`S_map = (peak − median(map))/MAD_sigma(map)`

是互相关图稳健对比度。搜索包含大量相关假设，S_map 不是标准正态显著性，不能把 320 的数值解释为“320σ 排除零假设”。

新版的真实搜索、自校准及三族零对照使用相同分辨率、保留种子数和细化预算；跳过自校准或零对照不得返回可晋级状态。两次试验×三族只有六个零对照，经验尾部分辨率最多 1/7，不能据此校准 99% 尾部或全局误报率。软件中的峰值倍数门是工程性支持检查，`VALIDATED` 仅表示通过此检查，不是物理真值认证。

后续测光须读取当前盲解报告，核验源表及参考表 SHA-256，并使用报告中的投影中心、尺度、旋转、镜像和平移。镜像定义为先反射再旋转。未附经过检查报告的手工种子结果标为 `DIAGNOSTIC_ONLY_UNVALIDATED_SEED`。

### 2.4 匹配、历元与经验拟合

新版从 MJD-OBS 或 DATE-OBS 取得观测历元；缺失时要求显式历元，避免沿用首帧的固定年份。DATE-OBS 未注明 TIMESYS 时仅按所写日历计算近似历元，不推断其时间系统。自行采用线性角位置传播，缺失自行按零近似；并非完整三维空间运动、视差和光行差模型。Astropy 的完整空间运动传播说明不能充当此简化 Rust 实现的等价性证明。

使用双向最近邻及稳健几何细化。拟合 `G_ref = m_inst + ZP`，有颜色的共同样本另拟合 `G_ref = m_inst + ZP + C(BP−RP)`。权重实际为

`w = 1 / max(σ_inst² + σ_G², 0.05²)`。

Gaia 有通量信噪比时，由 `(2.5/ln10)/(flux/error)` 近似转换星等误差；无误差字段时保持“未知”的元数据，0.05 mag 仅是显式权重地板，不表示 Gaia 的测量误差。还应进一步检查 RUWE、重复/混合、测光超额、变量星和孤立性；当前匹配与裁剪不代替这些质量审计。

零点逆法方程给出的标准误差是独立且给定权重条件下的形式误差；残差尺度修正的误差另列。共同平场、通带、参考表误差及相关残差不会因参考星多而自动消失。未知颜色目标使用零阶模型，不能把有色项模型的截距当作无颜色修正的目标零点。

### 2.5 验证及误差分离

固定随机种子仅控制分组，输入文件及参数也须冻结。零阶和一阶模型使用同一个预先确定的颜色完整样本及相同折分；每折只对训练集裁剪，所有留出星均评分，报告未裁剪 RMSE 和样本数。不能先用全数据残差选 inlier，再进行交叉验证；也不能剔除测试残差较大的星后将散度命名为预测精度。模型间 RMSE 略有降低也不是显著性检验。

空间分块留一检查空间外推；连续帧同星差分检查时间变化分量。重复空间图案只能证明共同结构，不能单独区分平场、位置相关匹配、参考星群颜色或混合效应。

对第 j 颗星的多帧平均，应使用包含协方差的模型：

`Var(m̄_j) = N⁻² Σ_f Var(e_jf) + 2N⁻² Σ_(f<k) Cov(e_jf,e_jk) + Var(s_j)`。

只有独立且同方差的随机部分才按 1/N 降低。总目录残差包含共同项；将其整体除以 √15 并不能测出合并后的外部精度。需实际配准同星、合并通量，并用独立参考/留出样本评估。

本节数字由本轮实际产物单独填入，见校验报告的运行记录。修正后的首帧结果不能替代全15帧复算；完整绝对标定精度、仪器标准通带、实测50%/90%完备深度及合并帧误差仍为【未知】。

## 5 波段解释和后续实验

Gaia DR3 的 G/BP/RP 通带与 EDR3 相同；与更早 release 的比较须核对相应系统。某些标准带变换拟合的0.07–0.12 mag残差依赖通带、样本与模型，不能证明本相机存在相同的不可突破误差下限。应实测本相机对独立参考星的颜色、亮度和位置相关残差。

结果应写为 `g_emp[Gaia DR3 G reference; response unknown; model_id; exposure; valid colour/magnitude/spatial ranges; held-out RMSE]`。Gaia XP可以为已指定通带生成合成测光，但不凭空恢复未知仪器响应。

优先实验：以新版同一估计器重做空孔径噪声；获取gain/读噪和异常码说明；用独立标准星与颜色完整样本验证；全15帧冻结复算并实际合并通量；测量平场/响应曲线。缺少gain不意味着源泊松噪声不随帧数改善；参数缺失造成误差预算不完整，与噪声本身的时间随机性是两件事。

## 6 结论

现有材料支持进一步开展Gaia参考的经验测光，并支持几何匹配、异常码排除及共同空间结构的研究。原稿尚不能证明0.038 mag的合并精度、光子极限、唯一安装偏置或完整系统误差分解。修正后的程序提供可追溯的条件测量、输入哈希、参数、全部留出评分与失败停止机制；其结果须连同误差模型缺项和适用样本范围引用。
