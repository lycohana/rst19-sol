# 光度标定科学性校验报告

审阅开始：2026-10-17；交付核验：2026-10-18。项目：RST19。仅代表本报告列明的文件、参数和实际运行。

## 校验结论

**原稿需要实质性修订，不能直接作为“绝对标定精度已验证、15帧达到0.038 mag”的论文结论。** 对应Rust实现存在会影响测量和验证的缺陷，已修正并接入测光套组。新版输出Gaia G参考的经验星等及条件误差；绝对精度、真实仪器通带、物理满阱和完整随机/系统误差分解仍未认证。

此次审阅没有运行Python；原先两份Rust独立二进制的主体提取为库模块，CLI和桌面worker调用同一套Rust实现。现有高级单项工具保留，测光套组改用经过本轮核查的新路径。

## 数学约定

F以每曝光ADU计，m_inst=−2.5log10(F)。小误差传播σ_m≈1.085736σ_F/F；低SNR与删失分布不保证正态。

g为e⁻/ADU，不是ADU/e⁻。采用fractional孔径时，背景方差项为κ²s_b²Σw²，环带中位数估计项近似(π/2)s_b²(Σw)²/N_b；正且已知gain才加入源泊松估计项。κ=1是未实测修正的默认值，历史1.18不能未经重测直接普遍套用。

对N帧平均：Var(m̄)=N⁻²ΣVar(e_f)+2N⁻²ΣCov(e_f,e_k)+Var(s_common)。总目录残差中的共同通带、参考表或位置项不自动除以√N。零点WLS形式误差也不代表同一目标的外部误差。
