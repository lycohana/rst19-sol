# 原始 FITS 数据目录

此目录用于存放比赛方提供的、已获授权的原始 FITS 数据。

当前本地数据集包含 15 个 FITS 文件，总大小约 480 MiB。由于原始数据的公开和再分发授权尚未在仓库中确认，FITS 文件通过仓库根目录的 `.gitignore` 忽略，不会随 Git 提交或 GitHub 克隆版本发布。

## 本地使用

将授权数据文件放入本目录后，可参考：

- [本地数据核验](../本地数据核验.md)：当前 15 个文件的尺寸、FITS 头和辅助数据抽检结果。
- [FITS 读取与校验](../../01-数据解析/FITS读取与校验.md)：读取、字节序、首行辅助数据和内存策略。
- [资料总索引](../../README.md)：全部赛题、算法和参考资料入口。

不要把 API Key、访问 Token 或未获授权的原始数据放入 Git 仓库、Issue、Pull Request 或公开附件。
